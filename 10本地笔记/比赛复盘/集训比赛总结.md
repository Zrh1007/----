# 题解

## 先加后乘 - addfirst


> [!info]+ 题意
>
> 给定一个长度为 $n$ 的数组 $a$，求 $(a_i + a_j) \times a_k$ 的最小值，其中 $1 \leq i,j,k \leq n \leq 10^5$ 且 $i,j,k$ 互不相同。



> [!info]+ 题解
>
>
> > [!warning]+ 模拟
> >
> > 使用三重循环或 DFS 枚举 $i,j,k$ 的组合，计算 $(a_i + a_j) \times a_k$ 的值，并记录最小值，最后输出。
> >
> > > [!warning]+ 模拟实现
> > >
> > > ```cpp
> > > #include <bits/stdc++.h>
> > > using namespace std;
> > > int n,a[100010];
> > > int minn=1e9;
> > > int main(){
> > >     cin>>n;
> > >     for(int i=1;i<=n;i++){
> > >         for(int j=1;j<=n;j++){
> > >             if(i==j) continue;
> > >             for(int k=1;k<=n;k++){
> > >                 if(i==k||j==k) continue;
> > >                 int temp=min((a[i]+a[j])*a[k],min((a[i]+a[k])*a[j],(a[j]+a[k])*a[i]));
> > >                 if(temp<minn) minn=temp;
> > >             }
> > >         }
> > >     }
> > >     cout<<minn;
> > >     return 0;
> > > }
> > > ```
> >
> >
> > > [!warning]+ 时间复杂度
> > >
> > > 时间复杂度：$O(n^3)$，由于题目限制 $n \leq 10^5$，该解法不可行。
> >
>
>
> > [!success]+ 优化
> >
> > 根据题意，不难发现，$a_i,a_j,a_k$ 有四种组合方式，分别是：两负一正、两正一负、三正、三负。因此我们可以分类讨论。
> > 1. 两负一正：如果要使 $(a_i + a_j) \times a_k$ 最小，那么 $a_i$ 和 $a_j$ 应该是两个最小的负数，而 $a_k$ 应该是最大的正数。
> > 2. 两正一负：如果要使 $(a_i + a_j) \times a_k$ 最小，那么 $a_i$ 和 $a_j$ 应该是两个最大的正数，而 $a_k$ 应该是最小的负数。
> > 3. 三正：如果要使 $(a_i + a_j) \times a_k$ 最小，那么 $a_i$、$a_j$ 和 $a_k$ 都应该是最小的正数。
> > 4. 三负：如果要使 $(a_i + a_j) \times a_k$ 最小，那么 $a_i$、$a_j$ 应是最大的负数，而 $a_k$ 应是最小的负数，这种情况只有在 $a$ 数组均为负数时才可能发生，因此正常情况下我们不需要考虑。
> >
> > 因此，我们可以先对 $a$ 数组进行分类，然后分别计算四种情况的最小值，最后输出每个分类的最小值。
> >
> > > [!success]+ 实现
> > >
> > > ```cpp
> > > #include<bits/stdc++.h>
> > > using namespace std;
> > > int n;
> > > long long a[100010];
> > > int main(){
> > >     ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
> > >     cin>>n;
> > >     for(int i=0;i<n;i++)cin>>a[i];
> > >     sort(a,a+n);
> > >     long long ans=1e9;
> > >    //1.最小两数+最大数
> > >     ans=min(ans,(a[0]+a[1])*a[n-1]);
> > >    //2.最大两数+最小数
> > >     ans=min(ans,(a[n-1]+a[n-2])*a[0]);
> > >    //3.前三小
> > >     for(int i=0;i<min(3,n);i++){
> > >         for(int j=i+1;j<min(3,n);j++){
> > >             for(int k=j+1;k<min(3,n);k++){
> > >                 ans=min(ans,(a[i]+a[j])*a[k]);
> > >                 ans=min(ans,(a[i]+a[k])*a[j]);
> > >                 ans=min(ans,(a[j]+a[k])*a[i]);
> > >             }
> > >         }
> > >     }          
> > >    //4.前三大
> > >     for(int i=max(0,n-3);i<n;i++){
> > >         for(int j=i+1;j<n;j++){
> > >             for(int k=j+1;k<n;k++){
> > >                 ans=min(ans,(a[i]+a[j])*a[k]);
> > >                 ans=min(ans,(a[i]+a[k])*a[j]);
> > >                 ans=min(ans,(a[j]+a[k])*a[i]);
> > >             }
> > >         }
> > >     }
> > >     cout<<ans;
> > >     return 0;
> > > }
> > > ```
> >
> >
> > > [!success]+ 时间复杂度
> > >
> > > 时间复杂度：$O(n log n)$
> >
>


## 异画师的技能组合-1 - combo1


> [!info]+ 题意
>
> 给定一个正整数序列 $a$ 和字符串 $s$ 以及初始变量 $ans$，其中 $ans=0$。  
> 字符串 $s$ 由 `Q` `W` `E` `R` 组成，表示四种技能。  
> 定义 `IDLE` 状态指当前字符的前一个字符不是 `Q`、`W`、`E` 之一。  
> 在此情况下，按下 `Q`、`W`、`E` 进入 `READY`，按下 `R` $ans$ 将立即增加 $a_10$。  
>
> `READY` 状态指在 `IDLE` 状态下，按下 `Q`、`W`、`E` 时进入的状态。  
> 在此状态下，按下 `Q`、`W`、`E` $ans$ 将增加 $a_1$ 到 $a_9$ 中的一个，按下 `R` 将回到 `IDLE` 状态。  
>
> $a$ 的长度为 $10$，且 $1 \leq a_i \leq 10^9$。  
> 设 `IDLE` 状态字符加 `READY` 状态字符的字符组为 $str$，则 $str$ 与 $a$ 数组的映射如下：
> `QQ` $= a_1$  
> `QW` $= a_2$  
> `QE` $= a_3$  
> `WQ` $= a_4$  
> `WW` $= a_5$  
> `WE` $= a_6$  
> `EQ` $= a_7$  
> `EW` $= a_8$  
> `EE` $= a_9$  
> `R` $= a_{10}$  
>
> 求遍历完整个字符串 $s$ 后，$ans$ 的值。



> [!info]+ 题解
>
>
> > [!success]+ 大模拟
> >
> > 根据题意，我们可以创建一个变量 $f$ 表示当前状态，初始值为 $1$ 表示 `IDLE` 状态，$2$ 表示 `READY` 状态。  
> > 然后遍历字符串 $s$，对于每个字符 $c$，根据当前状态 $f$ 进行相应操作：
> > - 如果 $f=1$，且 $c$ 为 `Q`、`W`、`E` 之一，则将 $f$ 变为 $2$。
> > - 如果 $f=2$，且 $c$ 为 `Q`、`W`、`E` 之一，则将 $ans$ 根据映射增加 $a_1$ 到 $a_9$ 中的一个，并将 $f$ 变为 $1$。
> > - 如果 $f=2$，且 $c$ 为 `R`，则将 $f$ 变为 $1$。
> >
> > > [!success]+ 大模拟实现
> > >
> > > ```cpp
> > > #include<bits/stdc++.h>
> > > using namespace std;
> > > int a[15];
> > > map<string,int> mp={{"QQ",1},{"QW",2},{"QE",3},{"WQ",4},{"WW",5},{"WE",6},{"EQ",7},{"EW",8},{"EE",9},{"R",10}};
> > > string s;
> > > long long sum;
> > > int main(){
> > >     for(int i=1;i<=10;i++) cin>>a[i];
> > >     cin>>s;
> > >     int f=0;
> > >     string str="";
> > >     for(int i=0;i<s.size();i++){
> > >         if(s[i]!='R'){
> > >             if(f==0){
> > >                 f=1;
> > >                 str=s[i];
> > >             }
> > >             else{
> > >                 str+=s[i];
> > >                 sum+=a[mp[str]];
> > >                 f=0;
> > >             }
> > >         }
> > >         else if(f==0){
> > >             sum+=a[mp["R"]];
> > >         }
> > >         else{
> > >             f=0;
> > >         }
> > >     }
> > >     cout<<sum;
> > >     return 0;
> > > }
> > > ```
> >
> >
> > > [!success]+ 大模拟时间复杂度
> > >
> > > 时间复杂度：$O(n)$
> >
>
