# gcd和lcm

> [!info]+ gcd和lcm
>
>
> > [!info]+ 定义
> >
> > - 最大公约数即为 Greatest Common Divisor，常缩写为 gcd。
> > - 一组整数的公约数，是指同时是这组数中每一个数的约数的数。$\pm 1$是任意一组整数的公约数。
> > - 最小公倍数（Least Common Multiple，LCM）是指两个或多个整数公有的倍数中最小的一个。
> > - 对于两个整数 $a$ 和 $b$，它们的最大公约数（gcd）是指能够同时整除 $a$ 和 $b$ 的最大整数。
> > - 例如，$gcd(8,12)=4$，$gcd(14,28)=14$。
> > - 最大公约数可以用欧几里得算法（Euclidean algorithm）来计算。
>
>
> > [!info]+ 性质
> >
> > 1. $gcd(a,b)=gcd(b,a \% b)$
> > 2. $gcd(a,b) \times lcm(a,b)=a \times b$
> > 3. $gcd(a,b,c) \leq min(a,b,c)$
>

# T715680 数学专题1-1


> [!info]+ 题意简化
>
> 给定数组 $a$，求 $gcd(a_1,a_2,\dots,a_n)$ 。



> [!info]+ 题解
>
>
> > [!info]+ 数学方法
> >
> > - 使用欧几里得算法（Euclidean algorithm）计算最大公约数。
> > - 设 $gcd(a,b)$ 为 $a$ 和 $b$ 的最大公约数，$lcm(a,b)$ 为 $a$ 和 $b$ 的最小公倍数。
> > - 则有 $gcd(a,b) \times lcm(a,b)=a \times b$。
> > - 因此，我们可以使用欧几里得算法（Euclidean algorithm）计算最大公约数。
> > - 当然，我们也可以使用C++标准库中的函数 `__gcd(a,b)` 来计算最大公约数。
> > - 具体的，我们可以先将数组 $a$ 中的第一个数作为最大公约数，然后依次用数组 $a$ 中的数与当前的最大公约数计算最大公约数。
> >
> > > [!success]+ 数学方法
> > >
> > > ```cpp
> > > #include<bits/stdc++.h>
> > > using namespace std;
> > > int n,a[1010];
> > > int main(){
> > >     ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
> > >     cin>>n;
> > >     for(int i=1;i<=n;i++){
> > >         cin>>a[i];
> > >     }
> > >     int ans=a[1];
> > >     for(int i=2;i<=n;i++){
> > >         ans=__gcd(ans,a[i]);
> > >     }
> > >     cout<<ans;
> > >     return 0;
> > > }
> > > ```
> >
> >
> > > [!success]+ 时间复杂度
> > >
> > > - 时间复杂度：$O(n)$，其中 $n$ 是数组 $a$ 的长度。
> >
>

# T715681 数学专题1-2


> [!info]+ 题意简化
>
> 给定长度为 $n$ 的整数序列 $a$，请构造一个整数序列 $b$ 满足对于所有 $1\le i\le n$，有 $1\le b_i \le a_i$。且 $\gcd(b_1,b_2,\cdots,b_n)$ 最大，其中 $\gcd$ 表示最大公因数。  
> 求能得到的最大 $\gcd(b_1,b_2,\cdots,b_n)$ 和对应的不同的 $b$ 的个数。



> [!info]+ 题解
>
>
> > [!info]+ 暴力解法
> >
> >  - 使用深度优先搜索（DFS）生成所有可能的数组 $b$，并计算每个数组的 $\gcd$ 值。
> >  - 具体的，我们可以使用一个桶 $tong$ 来记录每个 $\gcd$ 值出现的次数。
> >  - 并且，在搜索的过程中，我们可以记录下当前的 $\gcd$ 最大值 $maxn$。
> >  - 最后，输出 $maxn$ 和 $tong_{maxn}$ 即可。
> >
> > > [!warning]+ 暴力解法
> > >
> > > ```cpp
> > > #include<bits/stdc++.h>
> > > using namespace std;
> > > int n,a[100010],maxn=-1e9;
> > > int dis[100010];
> > > int tong[100010];
> > > void dfs(int u){
> > >     if(u>n){
> > >         int gcd=dis[1];
> > >         for(int i=2;i<=n;i++){
> > >             gcd=__gcd(gcd,dis[i]);
> > >         }
> > >         maxn=max(gcd,maxn);
> > >         tong[gcd]++;
> > >         return;
> > >     }
> > >     for(int i=1;i<=a[u];i++){
> > >         dis[u]=i;
> > >         dfs(u+1);
> > >     }
> > >     return;
> > > }
> > > int main(){
> > >     ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
> > >     cin>>n;
> > >     for(int i=1;i<=n;i++){
> > >         cin>>a[i];
> > >     }
> > >     dfs(1);
> > >     cout<<maxn<<' '<<tong[maxn];
> > >     return 0;
> > > }
> > > ```
> >
> >
> > > [!danger]+ 时间复杂度
> > >
> > > - 时间复杂度：$O(n \times 2^n)$，其中 $n$ 是数组 $a$ 的长度。
> >
>
>
> > [!success]+ 数学方法
> >
> > - 对于给定的 $n$，我们可以先求出 $a$ 的最小值 $minn$。
> > - 我们可以将 $a$ 中的每个数都除以 $minn$，并将结果取模 $mod$。
> > - 最后，将所有的结果相乘，即可得到 $\gcd(b_1,b_2,\cdots,b_n)$。
> >
> > > [!info]+ 原理
> > >
> > > - 已知 $gcd(b_1,b_2,\cdots,b_n) \leq min(b_1,b_2,\cdots,b_n)$ 。
> > > - 根据题意，我们需要使得 $\gcd(b_1,b_2,\cdots,b_n)$ 最大。
> > > - 所以 $\gcd(b_1,b_2,\cdots,b_n)$ 最大一定是 $minn$。
> > > - 但是，我们并不知道最后有多少种不同的 $b$ 序列。
> > > - 这时候，我们需要引入一个数学公式：$p(a) = a_1 \times a_2 \times \cdots \times a_n$，其中 $p(a)$ 表示 $a$ 数组所有可能的选择。
> > > - 因此，我们可以将 $a$ 中的每个数的选择数求出来，即 $\frac{a_i}{gcd}$。
> > > - 最后，将所有的选择数相乘，即可得到 $p(a)$。
> >
> >
> > > [!success]+ 数学方法
> > >
> > > ```cpp
> > > #include<bits/stdc++.h>
> > > using namespace std;
> > > int n,a[100010],minn=1e9;
> > > const int mod=1e9+7;
> > > int main(){
> > >     ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
> > >     cin>>n;
> > >     for(int i=1;i<=n;i++){
> > >         cin>>a[i];
> > >         minn=min(minn,a[i]);
> > >     }
> > >     long long ans=1;
> > >     for(int i=1;i<=n;i++){
> > >         ans*=a[i]/minn;
> > >         ans%=mod;
> > >     }
> > >     cout<<minn<<' '<<ans;
> > >     return 0;
> > > }
> > > ```
> >
> >
> > > [!success]+ 时间复杂度
> > >
> > > - 时间复杂度：$O(n)$，其中 $n$ 是数组 $a$ 的长度。
> >
>

# T715682 数学专题1-3


> [!info]+ 题意简化
>
> 给定 $n$ 个分数，求它们的和的最简形式。



> [!info]+ 题解
>
>
> > [!info]+ 模拟
> >
> > - 首先对于每个分数，我们可以将其表示为一个结构体，结构体中包含分子 $x$ 和分母 $y$。
> > - 在输入完字符串后，我们可以遍历字符串，将每个分数的分子分母储存到结构体当中。
> > - 然后，我们可以对每个分数进行处理：
> >   - 遍历结构体，将每个分数的分子分母进行处理。
> >   - 具体的，$\frac{a}{b}+\frac{c}{d}=\frac{ad+cb}{bd}$，我们可以计算出 $\frac{ad+cb}{bd}$ 的分子分母，并将其存入结构体中。
> > - 最后输出即可。
> >
> > > [!success]+ 模拟
> > >
> > > ```cpp
> > > #include<bits/stdc++.h>
> > > using namespace std;
> > > string s;
> > > struct node{
> > >     int x,y;
> > > }a[15];
> > > int main(){
> > >     ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
> > >     cin>>s;
> > >     int n=s.size(),ans=0,cnt=1;
> > >     for(int i=0;i<n;i++){
> > >         if(s[i]>='0'&&s[i]<='9'){
> > >             ans*=10;
> > >             ans+=s[i]-'0';
> > >         }
> > >         else{
> > >             if(s[i]=='/'){
> > >                 a[cnt].x=ans;
> > >                 ans=0;
> > >             }
> > >             else if(s[i]=='+'){
> > >                 a[cnt].y=ans;
> > >                 cnt++;
> > >                 ans=0;
> > >             }
> > >         }
> > >     }
> > >     if(ans!=0) a[cnt].y=ans;
> > >     int p=a[1].x,q=a[1].y;
> > >     for(int i=2;i<=cnt;i++){
> > >         p=p*a[i].y+a[i].x*q;
> > >         q=q*a[i].y;
> > >     }
> > >     int gcd=__gcd(p,q);
> > >     if(p/gcd==q/gcd) cout<<1;
> > >     else cout<<p/gcd<<'/'<<q/gcd;
> > >     return 0;
> > > }
> > > ```
> >
> >
> > > [!success]+ 时间复杂度
> > >
> > > - 时间复杂度：$O(n)$，其中 $n$ 是分数的数量。
> >
>

# T715685 数学专题1-4


> [!info]+ 题意简化
>
> 求满足 $gcd(a,b)=M$ 并且 $lcm(a,b)=N$ 的整数对 $(a,b)$ 的数量。



> [!info]+ 题解
>
>
> > [!info]+ 暴力枚举
> >
> > - 首先，我们可以将 $M$ 和 $N$ 分解质因数。
> > - 例如，$M=2\times 3\times 5$，则 $M=2\cdot 3\cdot 5=10$。
> > - 同理，$N=2\times 3\times 5$，则 $N=2\cdot 3\cdot 5=15$。
> > - 因此，我们可以得到 $gcd(a,b)=10$ 和 $lcm(a,b)=15$。
> > - 我们可以枚举 $a$ 和 $b$ 的范围，并判断是否满足 $gcd(a,b)=10$ 和 $lcm(a,b)=15$。
> >
> > > [!success]+ 暴力枚举
> > >
> > > ```cpp
> > > #include<bits/stdc++.h>
> > > using namespace std;
> > > bool check(long long x){
> > >     if(x<2) return 0;
> > >     for(long long i=2;i*i<=x;i++){
> > >         if(x%i==0) return 0;
> > >     }
> > >     return 1;
> > > }
> > > int main(){
> > >     ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
> > >     long long x,y;
> > >     cin>>x>>y;
> > >     long long m=x*y;
> > >     long long cnt=0,f=0;
> > >     for(long long i=x;i<=y;i++){
> > >         if(m%i==0&&m/i>=x&&m/i<=y&&__gcd(i,m/i)==x&&!check(i)&&!check(m/i)){
> > >             cout<<i<<' '<<m/i<<'\n';
> > >             f=1;
> > >         }
> > >     }
> > >     if(!f) cout<<-1;
> > >     return 0;
> > > }
> > >
> > > ```
> >
> >
> > > [!success]+ 时间复杂度
> > >
> > > - 时间复杂度：$O(\sqrt{M})$，其中 $M$ 是给定的 $M$。
> >
>
