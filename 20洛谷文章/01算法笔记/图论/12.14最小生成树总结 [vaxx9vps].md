# 最小生成树


> [!info]+ 定义
>
> 最小生成树（Minimum Spanning Tree，MST）是指在一个连通加权无向图中，选取一棵生成树，使得该生成树的边权之和最小。  
> 生成树是包含图中所有顶点的无环连通子图。




> [!info]+ 常用算法
>
> 1. **Kruskal算法**：基于边的贪心策略，按边权从小到大排序，依次选择边，若加入该边不会形成环，则将其加入生成树，直到生成树包含所有顶点。  
>
> > [!success]+ 实现
> >
> > 图示：
> > ![Kruskal算法](../../../80%E9%99%84%E4%BB%B6/image-8821d6ee7458cc4a.apng)
> > 实现：
> > ```cpp
> > struct node{
> >     int u,v,w;
> > };
> > bool cmp(node x,node y){
> >     return x.w<y.w;
> > }
> > for(int i=1;i<=m;i++){
> >     int u,v,w;//边的两个端点和权值
> >     cin>>u>>v>>w;
> >     a[i]={u,v,w};
> > }
> > sort(a+1,a+m+1,cmp);
> > ```
>
> Kruskal算法需要使用并查集（Union-Find）来检测环路。
>
> > [!success]+ 并查集实现
> >
> > ```cpp
> > int p[100010];

> >     if(p[x]!=x) p[x]=find(p[x]);
> >     return p[x];
> > }
> > ```
