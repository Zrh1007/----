# 分解质因数


> [!info]+ 定义
>
> 质因数（prime factorization）是指将一个正整数分解为质数的乘积。
> 比如 $12=2^2\times3$。  
> 分解质因数的目的是为了方便计算。    
> 比如 $12=2^2\times3$，则 $12$ 可以分解为 $2$ 的 $2$ 次幂和 $3$ 的 $1$ 次幂的乘积。  
> 分解质因数的过程称为质因数分解。  



> [!info]+ 实现算法
>
> 1. **朴素算法**：最简单的算法即为从 $2$ 开始，直到 $n$ 为 $1$ 时停止，如果 $n$ 能被 $i$ 整除，则将 $i$ 记录为质因数，并将 $n$ 除以 $i$。重复这个过程，直到 $n$ 为 $1$。
>
> > [!success]+ 实现
> >
> > ```cpp
> > vector<int> f(int N){
> >     vector<int> result;
> >     for(int i=2;i*i<=N;i++){
> >         if(N%i==0){  // 如果 i 能够整除 N，说明 i 为 N 的一个质因子。
> >             while(N%i==0) N/=i;
> >             result.push_back(i);
> >         }
> >     }
> >     if(N!=1){  // 说明再经过操作之后 N 留下了一个素数
> >         result.push_back(N);
> >     }
> >     return result;
> > }
> > ```
>
>
> > [!success]+ 关于时间复杂度
> >
> > - 时间复杂度：$O(\sqrt{n})$，其中 $n$ 为待分解的正整数。
>


# 唯一分解定理


> [!info]+ 定义
>
> 唯一分解定理（Unique factorization theorem）是指**任何大于 $1$ 的正整数 $n$，都能唯一表示为有限个质数的乘积**：
>
> $$
> n=p_1^{a_1}\times p_2^{a_2}\times\cdots\times p_k^{a_k}
> $$
>
> 其中 $p_i$ 为互不相同的质数，$a_i$ 为正整数，且保证 $p$ 序列唯一。  
> 比如 $12=2^2\times3$，则 $12$ 只能分解为 $2$ 的 $2$ 次幂和 $3$ 的 $1$ 次幂的乘积。  



> [!info]+ 证明
>
> 首先证明存在性：
>
> > [!success]+ 存在性证明
> >
> > 定义 $n$ 为正整数，且 $2 \leq n$。  
> > 1. 如果 $n$ 为 $2$，则 $n$ 只能分解为 $2$ 的 $1$ 次幂，即 $n=2^1$，显然存在。
> > 2. 假设 $2 \leq x \leq n$ 的正整数 $x$ 都能分解为质数乘积：
> >    - 如果 $x$ 为质数，则 $x$ 能分解为 $x$ 的 $1$ 次幂，即 $x=p$，显然存在。
> >    - 如果 $x$ 为合数，则应存在 $p$ 和 $q$，使得 $x=p\times q$，且 $2 \leq p,q \leq x$。
> >    - 由于假设 $2 \leq x \leq n$ 的正整数 $x$ 都能分解为质数乘积，且 $x$ 为合数，因此 $x = p\times q$，且 $p$ 和 $q$ 都是质数，存在性成立。  
> >    - 
> > 证毕。
>
> 然后证明唯一性：
>
> > [!success]+ 唯一性证明
> >
> > - 假设 $n$ 为正整数，且 $2 \leq n$。
> > - 假设 $n$ 有两种分解方式：$n=p_1^{a_1}\times p_2^{a_2}\times\cdots\times p_k^{a_k}$ 和 $n=q_1^{b_1}\times q_2^{b_2}\times\cdots\times q_l^{b_l}$。
> > - 其中所有的 $p_i$ 和 $q_i$ 为互不相同的质数，或 $p_i$ 和 $q_i$ 相同，但 $a_i \neq b_i$。
> > - 首先消除公共质数，由于 $p_1$ 整除 $n$，所以 $p_1$ 一定可整除 $q_1^{b_1}\times q_2^{b_2}\times\cdots\times q_l^{b_l}$。
> > - 根据质数性质，$p_1$ 一定整除 $q_i$ （根据乘法的性质，暂时将 $i = 1$ 代入），又由于 $q_i$ 为质数，所以 $p_1 = q_i$。
> > - 再约去公共质数，将两边同时除以 $p_1^{min(a_1,b_1)}$，如果 $a_1 > b_1$，则左边为 $p_1^{a_1-b_1}$，右边无 $p_1$，与“两边相等”矛盾；同理 $a_1 < b_1$ 也矛盾，因此 $a_1 = b_1$。
> > - 约去 $p_1^{a_1}$后，剩余部分相等，重复上述步骤，最终所有的 $p_i$ 和 $q_i$ 都相同，所以 $n$ 只有一种分解方式。  
> > 证毕。
>


# 例题：

# B2138 最大质因子序列


> [!info]+ 题意简化
>
> 给定两个正整数 $m,n$，求 $m$ 到 $n$ 之间每个数的最大质因子，输出以逗号间隔。



> [!info]+ 题解
>
>
> > [!info]+ 暴力枚举
> >
> > 暴力枚举法，枚举每个数 $i$，然后求 $i$ 的最大质因子。
> >
> > > [!success]+ 枚举实现
> > >
> > > ```cpp
> > > #include<bits/stdc++.h>
> > > using namespace std;
> > > int m,n;
> > > bool f(int x){ // 判断 x 是否为质数
> > > 	if(x<2) return 0;
> > > 	for(int i=2;i*i<=x;i++){
> > > 		if(x%i==0) return 0;
> > > 	}
> > > 	return 1;
> > > }
> > > int check(int x){ // 计算 x 的最大质因子
> > > 	if(f(x)) return x; // 如果 x 为质数，则返回 x
> > > 	int y=x; //保存初始 x
> > > 	while(x>1){ // 否则，将 x 除以质数，直到 x 为质数
> > > 		x--; // 注意：这里不能用 x/=2，因为最后可能有余数
> > > 		if(y%x==0&&f(x)) return x; // 如果 x 为质数，则返回 x
> > > 	}
> > > 	return x; // 如果 x 已经为 1，则返回 1
> > > }
> > > int main(){
> > > 	cin>>m>>n;
> > > 	for(int i=m;i<=n;i++){
> > > 		if(i!=m) cout<<','<<check(i); // 输出逗号
> > > 		else cout<<check(i); // 输出第一个数
> > > 	}
> > > 	return 0;
> > > }
> > > ```
> >
> >
> > > [!success]+ 时间复杂度
> > >
> > > - 时间复杂度 $O(n^2)$，其中 $n$ 为 $m$ 到 $n$ 之间数的个数。
> > > - 可以优化到 $O(n\log n)$，具体方法见下。
> >
>
>
> > [!info]+ 试除法
> >
> > 首先由于唯一分解定理，任何一个数都可以分解为若干个质数的乘积。  
> > 因此，我们可以先保存 $n$，$x = n$。  
> > 然后枚举 $i$，$2 \leq i \leq x$。  
> > 如果 $i$ 能整除 $x$，则将 $i$ 记录为质因数，并将 $x$ 除以 $i$。  
> > 重复这个过程，直到 $x$ 为 $1$。  
> >
> > > [!success]+ 试除法实现
> > >
> > > ```cpp
> > > #include<bits/stdc++.h>
> > > using namespace std;
> > > long long m,n;
> > > int main(){
> > >     cin>>m>>n;
> > >     for(long long i=m;i<=n;i++){
> > >         long long x=i,maxn=0; //质因数分解：试除法，从2开始试除
> > >         for(long long j=2;j<=i;j++){
> > >             while(x%j==0){ //j 不可能为合数？ 
> > >                 x/=j;
> > >                 maxn=max(maxn,j);
> > >             }
> > >             if(x==1) break;
> > >         }
> > >         if(i>m) cout<<","<<maxn;
> > >         else cout<<maxn;
> > >     }
> > >     return 0;
> > > }
> > > ```
> >
> >
> > > [!success]+ 时间复杂度
> > >
> > > - 时间复杂度 $O(\sqrt{n}\log n)$。
> >
>
