# 单调栈


> [!info]+ 定义
>
> 单调栈是一种特殊的栈数据结构，满足以下条件：  
> - 栈内元素按照某种单调关系排列（例如单调递增或单调递减）。  
> - 当新元素入栈时，如果不满足单调关系，则需要弹出栈顶元素，直到满足单调关系为止。  
> 单调栈常用于解决一些与数组相关的问题，例如寻找下一个更大元素、寻找下一个更小元素等。



> [!success]+ 过程
>
> ## 插入
>
> 将一个元素插入单调栈时，为了维护单调关系，需要弹出栈顶元素，直到满足单调关系为止。  
> 例如，现在栈中元素自顶而下为 ${0,11,45,81}$  
> ![单调栈插入示例](../../../80%E9%99%84%E4%BB%B6/image-50d614d6504a3966.svg)  
> 如果要插入元素 $14$，那么为了维护单调递增关系，需要弹出 $0$ 和 $11$，最终栈中元素自顶而下为 ${14,45,81}$  
> ![单调栈插入示例](../../../80%E9%99%84%E4%BB%B6/image-cd9c6a433c1f65b0.svg)  
> 实现如下:
> ```cpp
> stack<int> s;
>
> int x; // 读取要插入的元素 x
> while(!s.empty()&&s.top()>x){ // 如果栈顶元素大于 x
>     s.pop(); // 弹出栈顶元素
> }
> q.push(x); // 将 x 插入栈中
> ```
> ---
> ## 使用
>
> 从栈顶读出一个元素，该元素就是满足单调关系的下一个元素。  
> 例如，现在栈中元素自顶而下为 ${14,45,81}$，那么从栈顶读出一个元素 $14$，就可以知道 $14$ 是栈中最小的元素。



> [!success]+ 应用
>
> 来看一个例题：  
>
> > [!info]+ P5788 【模板】单调栈
> >
> > 给定一个长度为 $n$ 的数组 $a$，对于每个元素 $a_i$，求出它右边第一个比它大的元素，如果不存在则输出 $0$。
>
> 我们还是来分析一下题目：
> 求出每个元素右边第一个比它大的元素，这个问题可以使用单调栈来解决。
> 我们可以维护一个单调递增的栈，栈中存储元素的索引。当我们遍历数组时，对于每个元素 $a_i$，我们需要弹出栈顶元素，直到栈顶元素对应的值大于 $a_i$。如果栈不为空，那么栈顶元素对应的值就是 $a_i$ 右边第一个比它大的元素；如果栈为空，则说明 $a_i$ 右边没有比它大的元素，我们输出 $0$。最后，我们将当前元素的索引入栈。
> 实现如下：
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> int n,a[3000010],f[3000010]; // f[i] 存储 a[i] 右边第一个比它大的元素的索引，如果不存在则为 0
> stack<int> s; // 存储元素索引的单调栈
> int main(){
>     ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
>     cin>>n;
>     for(int i=1;i<=n;i++) cin>>a[i]; // 读取数组元素
>     for(int i=1;i<=n;i++){
>         while(s.size()&&a[s.top()]<a[i]){ // 如果栈不为空且栈顶元素对应的值小于 a[i]
>             f[s.top()]=i; // 栈顶元素对应的值就是 a[i] 右边第一个比它大的元素
>             s.pop(); // 弹出栈顶元素
>         }
>         s.push(i); // 将当前元素的索引入栈
>     }
>     for(int i=1;i<=n;i++){ // 输出结果
>         cout<<f[i]<<' ';
>     }
>     return 0;
> }
> ```
>
> > [!success]+ 时间复杂度
> >
> > 单调栈的时间复杂度为 $O(n)$，因为每个元素最多被入栈和出栈各一次。
>


# 例题

## P12241 [蓝桥杯 2023 国 C] 最大区间

> [!info]+ 题意
>
> 给定一个长度为 $n$ 的数组 $a$，求 $L,R$ 使得 $(R-L+1)\times \min_{L\le i\le R} a_i$ 最大。



> [!info]+ 分析
>
> 根据题意，我们需要找到一个长度尽可能大的最小值最大的区间，使得 $(R-L+1)\times \min_{L\le i\le R} a_i$ 最大。  
> 不难发现，在最小值确定的情况下，区间长度越大，结果越大。因此，对于每个元素 $a_i$，我们需要找到它左边第一个比它小的元素和右边第一个比它小的元素，这样就可以确定以 $a_i$ 为最小值的区间长度。



> [!success]+ 解法
>
> 根据分析，我们可以使用单调栈来找到每个元素左边第一个比它小的元素和右边第一个比它小的元素。  
> 所以，我们可以维护一个不下降单调栈，运行两次，第一次从左到右遍历数组，找到每个元素左边第一个比它小的元素；第二次从右到左遍历数组，找到每个元素右边第一个比它小的元素。    
> 由于题目数据范围为 $3 \times 10^5$，此解法的时间复杂度为 $O(2\times n)$ ，可行。
> 实现如下：
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> int n,l[300010],r[300010];// l[i] 存储 a[i] 左边第一个比它小的元素的索引，如果不存在则为 0，r[i] 同理
> long long a[300010],ans;
> stack<int> s; // 存储元素索引的单调栈
> int main(){
>     ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
>     cin>>n;
>     for(int i=1;i<=n;i++) cin>>a[i];
>     for(int i=1;i<=n;i++){
>         while(s.size()&&a[s.top()]>=a[i]) s.pop();// 如果栈不为空且栈顶元素对应的值大于等于 a[i]
>         if(s.size()) l[i]=s.top(); // 栈顶元素对应的值就是 a[i] 左边第一个比它小的元素
>         else l[i]=0; // 如果栈为空，则说明 a[i] 左边没有比它小的元素，我们输出 0
>         s.push(i); // 将当前元素的索引入栈
>     }
>     while(s.size()) s.pop(); // 清空栈，准备寻找右边第一个比它小的元素
>     for(int i=n;i>=1;i--){
>         while(s.size()&&a[s.top()]>=a[i]) s.pop(); // 如果栈不为空且栈顶元素对应的值大于等于 a[i]
>         if(s.size()) r[i]=s.top(); // 栈顶元素对应的值就是 a[i] 右边第一个比它小的元素
>         else r[i]=n+1; // 如果栈为空，则说明 a[i] 右边没有比它小的元素，我们输出 n+1
>         s.push(i); // 将当前元素的索引入栈
>     }
>     for(int i=1;i<=n;i++) ans=max(ans,1ll*(r[i]-l[i]-1)*a[i]); // 计算以 a[i] 为最小值的区间长度，并更新答案
>     cout<<ans; // 输出结果
>     return 0;
> }
> ```



## P1901 [NOI 导刊] 发射站


> [!info]+ 题意
>
> 给定 $N$ 个发射站，每个发射站有一个高度 $H_i$ 和一个能量值 $V_i$。每个发射站向两边发射价值 $V_i$ 的能量，能量只被两边最近的且比它高的发射站接收。求接收最多能量的发射站接收的能量值。



> [!info]+ 分析
>
> 根据题意，我们需要找到每个发射站左边比它高的发射站和右边比它高的发射站，这样就可以确定每个发射站接收的能量值。



> [!success]+ 解法
>
> 根据分析，我们可以使用单调栈来找到每个发射站左边比它高的发射站和右边比它高的发射站。  
> 所以，我们可以维护一个单调递增的栈，运行两次，第一次从左到右遍历数组，找到每个发射站左边比它高的发射站；第二次从右到左遍历数组，找到每个发射站右边比它高的发射站。  
> 最后，我们计算每个发射站接收的能量值，并找到接收最多能量的发射站接收的能量值。  
> （怎么这么熟悉啊，感觉和上题很像啊）  
> 此解法的时间复杂度为 $O(2\times n)$ ，可行。（怎么感觉和上题一样啊）    
> 代码实现如下：
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> int n;
> int h[1000010],v[1000010]; // h[i] 存储第 i 个发射站的高度，v[i] 存储第 i 个发射站的能量值
> int l[1000010],r[1000010]; // l[i] 存储第 i 个发射站左边第一个比它高的发射站的索引，如果不存在则为 0，r[i] 同理
> long long f[1000010]; // f[i] 存储第 i 个发射站接收的能量值，初始值为 0
> stack<int> s; // 存储发射站索引的单调栈，栈内元素按照高度单调递增排列
> int main(){
> 	ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
> 	cin>>n;
> 	for(int i=1;i<=n;i++)cin>>h[i]>>v[i]; // 读取发射站的高度和能量值
> 	for(int i=1;i<=n;i++){
> 		while(s.size()&&h[s.top()]<h[i]){ // 如果栈不为空且栈顶元素对应的高度小于 h[i]
> 			s.pop(); // 弹出栈顶元素
> 		}
> 		if(s.size())l[i]=s.top(); // 栈顶元素对应的高度就是 h[i] 左边第一个比它高的发射站
> 		s.push(i); // 将当前发射站的索引入栈
> 	}
> 	while(s.size())s.pop(); // 清空栈，准备寻找右边第一个比它高的发射站
> 	for(int i=n;i>=1;i--){
> 		while(s.size()&&h[s.top()]<h[i]){ // 如果栈不为空且栈顶元素对应的高度小于 h[i]
> 			s.pop(); // 弹出栈顶元素
> 		}
> 		if(s.size())r[i]=s.top(); // 栈顶元素对应的高度就是 h[i] 右边第一个比它高的发射站
> 		s.push(i); // 将当前发射站的索引入栈
> 	}
> 	for(int i=1;i<=n;i++){ // 计算每个发射站接收的能量值
> 		if(l[i])f[l[i]]+=v[i];
> 		if(r[i])f[r[i]]+=v[i];
> 	}
> 	long long ans=0; // 存储接收最多能量的发射站接收的能量值
> 	for(int i=1;i<=n;i++){
> 		ans=max(ans,f[i]); // 更新答案
> 	}
> 	cout<<ans; // 输出结果
> 	return 0;
> }
>
> ```
