# U460099 结点的度

## 简化题意

> 给定一个有 $N$ 个结点，$M$ 条边的无向图，求每个结点的度。

## 思路

> 1\. 存储节点度
>
> - 使用一个数组 $deg$ 来存储每个节点的度，初始值为 $0$。

> 2\. 遍历每条边
>
> - 对于每条边 $(u,v)$，将 $u$ 和 $v$ 的度分别加 $1$。

> 3\. 输出结果
>
> - 遍历数组 $deg$，输出每个节点的度。

> 4\. 复杂度分析
>
> - 时间复杂度：$O(N+M)$，其中 N 是节点数，M 是边数。
> - 空间复杂度：$O(N)$，用于存储节点度的数组。

## 代码实现

```cpp
#include<bits/stdc++.h>
using namespace std;
int sum[5010],n,m;
int main(){
	ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);//输入输出优化（非必须）
	cin>>n>>m;
	for(int i=1;i<=m;i++){
		int u,v;
		cin>>u>>v;
		sum[u]++;// u和v中间有一条边，u的度加1
		sum[v]++;// v的度加1
	}
	for(int i=1;i<=n;i++) cout<<sum[i]<<'\n';
	return 0;
}
```

# U460103 图的类型

## 简化题意

> 给出一张有 $N$ 个点，$M$ 条边。无向连通图，没有重边和自环，判断这张图是否是一个链图 ($Chain$)、简单环 (Ring) 或者是菊花图 ($Flower$)，或者什么都不是 ($Neither$)。

## 思路

> 1. 判断链图
>
> - 观察链图的特点：链图是一个只有两个度为 $1$ 的节点，所有其他节点的度都是 $2$。
>   - 如果度为 $1$ 的节点数为 $2$，且所有其他节点的度都是 $2$，则图是链图。![](../../../80%E9%99%84%E4%BB%B6/image-7b3431ab0f113604.png)

> 2. 判断简单环
>
> - 观察简单环的特点：简单环是一个所有节点的度都是 $2$ 的图。
>   - 如果所有节点的度都为 $2$，则图是简单环。\
>     ![](../../../80%E9%99%84%E4%BB%B6/image-092aa331c367f8ca.png)
>
> 3. 判断菊花图
>
> - 观察菊花图的特点：菊花图是一个中心节点的度等于 $n-1$，且所有其他节点的度为 $1$ 的图。
>   - 如果中心节点的度等于 $n-1$，则图是菊花图。\
>     ![](../../../80%E9%99%84%E4%BB%B6/image-0e2d3418b897e883.png)
>
> 4. 总结
>
> - 如果图是链图，则输出“Chain”。
>
> - 如果图是简单环，则输出“Ring”。
>
> - 如果图是菊花图，则输出“Flower”。
>
> - 如果图不属于以上三种类型，则输出“Neither”。
>
> 5. 复杂度分析
>
> - 时间复杂度：$O(N+M)$，其中 N 是节点数，M 是边数。
> - 空间复杂度：$O(N)$，用于存储节点度的数组。

## 代码实现

```cpp
#include<bits/stdc++.h>
using namespace std;
int deg[1000010],n,m;
int main(){
	ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
	cin>>n>>m;
	for(int i=1;i<=m;i++){
		int u,v;
		cin>>u>>v;
		deg[u]++;// u的度加1
		deg[v]++;// v的度加1
	}
	int cnt1=0;
	int cnt2=0;
	int cnt3=0;
	for(int i=1;i<=n;i++){
		cnt1+=(deg[i]==1);//度为1的节点数
		cnt2+=(deg[i]==2);//度为2的节点数
		cnt3+=(deg[i]!=1&&deg[i]!=2);//其他情况
	}
	if(cnt2==n) cout<<"Ring";//简单环
	else if(cnt2==n-2&&cnt1==2) cout<<"Chain";//链图
	else if(cnt3==1&&cnt1==n-1) cout<<"Flower";//菊花图
	else cout<<"Neither";//都不是
	return 0;
}
```

# U460106 树和图

## 简化题意

> 给出一个节点有编号的无向图，和一棵树，求至少要加多少边才能将这棵树变成给定的图（对应节点之间的边相同），如果无法变成，则输出 $impossible$。

## 思路

> 1. 存储图和树
>
> - 使用邻接表存储图和树。
>
> - 使用一个数组记录每个节点的度。
>
> 2. 统计需要添加的边
>
> - 遍历树的每个边，如果在图中不存在对应的边，则需要添加这条边。
>
> 3. 判断是否可以转换
>
> - 如果需要添加的边数大于剩余的边数，则输出 $impossible$。
>
> - 否则，输出需要添加的边数。
>
> 4. 复杂度分析
>
> - 时间复杂度：$O(N+M)$，其中 N 是节点数，M 是边数。
> - 空间复杂度：$O(N+N^2+N^2)$，用于存储图和树。

## 代码实现

```cpp
#include<bits/stdc++.h>
using namespace std;
int n,m,cnt,a[10010];
bool vis[10010][10010];
int main(){
	ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
	cin>>n>>m;
	for(int i=1;i<n;++i){
		int d,u;
		cin>>u>>d;
		vis[u][d]=1;
		vis[d][u]=1;
	}
    for(int i=1;i<=m;++i){
        int u,v;
        cin>>u>>v;
        if(!vis[u][v] && !vis[v][u]){ // 图的边在树中不存在
            cnt++; // 需要添加这条边
        }
    }
    cout<<cnt;
	return 0;
}
```

# B3643 图的存储

## 简化题意

> 给定一个 $n$ 个顶点 $m$ 条边的无向图。请以邻接矩阵和邻接表的形式输出这一张图。

## 思路

> 1. 使用邻接矩阵存储图
>
> - 创建一个 $n \times n$ 的矩阵，初始值为 $0$。
>
> - 对于每条边 $(u,v)$，将矩阵的 $u$ 行 $v$ 列和 $v$ 行 $u$ 列的值设为 $1$。
>
> 2. 使用邻接矩阵存储邻接表
>
> - 在输入时，使用一个数组存储每个节点的度。
>
> - 在输出时，如果需要输出邻接表，则遍历每个节点的邻接矩阵，输出其邻接的节点。
>
> 3. 复杂度分析
>
> - 时间复杂度：$O(N^2+M)$，其中 $N$ 是节点数，$M$ 是边数。
> - 空间复杂度：$O(N^2+N)$，用于存储邻接矩阵和邻接表。

## 代码实现

```cpp
#include<bits/stdc++.h>
using namespace std;
bool deg[1010][1010];
int n,m;
int a[1010];
int main(){
	ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
	cin>>n>>m;
	for(int i=1;i<=m;i++){
		int u,v;
		cin>>u>>v;
		a[u]++;
		a[v]++;
		deg[u][v]=1;
		deg[v][u]=1;
	}
	for(int i=1;i<=n;i++){
		for(int j=1;j<=n;j++){
			cout<<deg[i][j]<<' ';
		}
		cout<<'\n';
	}
	for(int i=1;i<=n;i++){
		cout<<a[i]<<' ';
		for(int j=1;j<=n;j++){
			if(deg[i][j]) cout<<j<<' ';
		}
		cout<<'\n';
	}
	return 0;
}
```
