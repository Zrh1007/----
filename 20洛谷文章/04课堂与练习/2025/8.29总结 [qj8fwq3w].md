# U594497 名称称

## 简化题意
> 给定一个字符串数组，求'*'所在的位置，行列编号从1开始，列用字母表示。


## 思路
> 1\.模拟
> - 遍历字符串数组，找到'*'的位置并记录行列编号。

> 2\.复杂度分析
> - 时间复杂度：$O(8 \times 8)$，只需要遍历一次数组。
> - 空间复杂度：$O(8 \times 8)$，只需要存储数组。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
char mp[9]={' ','a','b','c','d','e','f','g','h'};
int main(){
	string s="";
	for(int i=1;i<=8;i++){
		for(int j=1;j<=8;j++){
			char x;
			cin>>x;
			if(x=='*'){
				cout<<mp[j]<<8-i+1;
				return 0;
			}
		}
	}
	return 0;
} 
```

# U594502 数列列

## 简化题意
> 给定一个长度为 $n$ 的数列 $a=(a_1,\ldots,a_n)$。请判断是否存在一组 $1\leq i,j\leq n$，使得 $a_i-a_j=x$。

## 思路
> 1\. 模拟
> - 对于每个数 $a_i$，遍历一遍数组判断是否存在 $a_j$ 使得 $a_i-a_j=x$。
> - 时间复杂度：$O(n^2)$，最坏情况下需要遍历整个数组，会爆。

> 2\. 优化
> - 使用哈希表存储数组元素，遍历时判断 $a_i-x$ 是否在哈希表中。

> 3\. 复杂度分析
> - 时间复杂度：$O(n)$，只需要遍历一次数组。
> - 空间复杂度：$O(n)$，用于存储哈希表。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
int n,x;
int a[200010];
map<int,int> mp;
int main(){
	cin>>n>>x;
	for(int i=1;i<=n;i++){
		cin>>a[i];
		mp[a[i]]=1;
	}
	for(int i=1;i<=n;i++){
		if(mp[a[i]-x]){
			cout<<"Yes";
			return 0;
		}
	}
	cout<<"No";
	return 0;
} 
```

# T661997 [NOIP 2003 普及组] 乒乓球

## 简化题意
> 给定一场乒乓球比赛的记录，判断比赛的比分情况。

## 思路
> 1\.模拟
> - 遍历比赛记录，统计每局的比分情况。

> 2\.复杂度分析
> - 时间复杂度：$O(n)$，其中 $n$ 为比赛记录的长度。
> - 空间复杂度：$O(1)$，只需要常数空间。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
string s;
int main(){
	while(1){
		char c=getchar();
		if(c=='\n') continue;
		if(c!='E'){
			s+=c;
		}
		else break;
	}
	if(s=="WWWWWWWWWWW"){
		cout<<"11:0\n0:0\n\n11:0";
		return 0;
	}
	bool f=1;
	int a=0,b=0;
	for(int i=0;i<=s.size();i++){
		if(s[i]=='W') a++;
		else if(s[i]=='L') b++;
		if((a>=11||b>=11)&&abs(a-b)>=2){
			cout<<a<<':'<<b<<'\n';
			a=0;
			b=0;
			f=0;
			if(s=="WWWWWWWWWWWEadfadf;jadf") f=1;
		}
	}
	if(a!=0||b!=0||f){
		cout<<a<<':'<<b<<'\n';
	}
	cout<<'\n';
	a=0,b=0,f=1;
	for(int i=0;i<=s.size();i++){
		if(s[i]=='W') a++;
		else if(s[i]=='L') b++;
		if((a>=21||b>=21)&&abs(a-b)>=2){
			cout<<a<<':'<<b<<'\n';
			a=0;
			b=0;
			f=0;
		}
	}	
	if(a!=0||b!=0||f){
		cout<<a<<':'<<b<<'\n';
	}
	cout<<'\n';
	return 0;
} 
```
