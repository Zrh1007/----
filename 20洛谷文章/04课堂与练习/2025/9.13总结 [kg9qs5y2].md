# P13797 [SWERC 2023] Programming-trampoline-athlon!

## 简化题意
> 计算每队总分（编程题数×10 + 蹦床去掉最高最低4个评分和），然后找出所有排名前3（即严格高于它的队伍数≤2，包括并列的情况）的队伍，按总分降序（同分按输入顺序）输出。


## 思路
> 1\.模拟
> - 计算每队的总分，并记录队伍信息。
> - 对队伍按总分降序排序，输出前3名。

> 2\.复杂度分析
> - 时间复杂度：$O(n \log n)$，其中 $n$ 为队伍数量，排序需要 $O(n \log n)$ 时间。
> - 空间复杂度：$O(n)$，用于存储队伍信息。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
int n;
int b[7]; 
struct node{
	int sum;
	int id;
	string s;
}a[100010];
bool cmp(node x,node y){
	if(x.sum!=y.sum) return x.sum>y.sum;
	return x.id<y.id;
}
int main(){
	cin>>n;
	for(int i=1;i<=n;i++){
		string p;
		cin>>p;
		a[i].id=i;
		a[i].s=p;
		int x;
		cin>>x;
		a[i].sum+=x*10;
		for(int j=1;j<=6;j++){
			cin>>b[j];
		}
		sort(b+1,b+7);
		a[i].sum+=+b[2]+b[3]+b[4]+b[5];
	}
	sort(a+1,a+1+n,cmp);
	for(int i=1;i<=n;i++){
		int cnt=0;
		for(int j=1;j<i;j++){
			if(a[j].sum>a[i].sum){
				cnt++;
				if(cnt>2) break;
			}
		}
		if(cnt>2) continue;
		cout<<a[i].s<<' '<<a[i].sum<<'\n';
	}
	return 0;
} 
```

# P1029 [NOIP 2001 普及组] 最大公约数和最小公倍数问题

## 简化题意
> 给定两个正整数 $x_0, y_0$，求出正整数对 $(P, Q)$ 的个数，满足：$\gcd(P, Q) = x_0$ $\&$ $\text{lcm}(P, Q) = y_0$

## 思路
> 1\. 模拟
> - 遍历每个可能的因子，计算满足条件的 $(P, Q)$ 对数。
> - 时间复杂度：$O(\sqrt{y_0})$，因为只需遍历到 $\sqrt{y_0}$，会爆。

> 2\. 优化
> - 使用质因数分解的方法，计算出 $y_0 / x_0$ 的质因数个数 $k$，则满足条件的 $(P, Q)$ 对数为 $2^{k-1}$。

> 3\. 复杂度分析
> - 时间复杂度：$O(\sqrt{y_0})$，质因数分解需要遍历到 $\sqrt{y_0}$。
> - 空间复杂度：$O(1)$，只需要常数空间。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
int x,y,cnt;//__gcd
int main(){
	cin>>x>>y;
	if(x==y) cnt--;
	for(int i=1;i<=int(sqrt(x*y))+1;i++){
		if((y*x)%i==0&&__gcd(i,(y*x)/i)==x){
			cnt+=2; 
		}
	}
	cout<<cnt;
	return 0;
} 
```

# T665889 数矩形

## 简化题意
> 给定N个点，计算所有由四个不同点组成且四条边均平行于坐标轴的矩形的数量。

## 思路
> 1\.模拟
> - 枚举每对点作为矩形的对角线，检查另外两个点是否存在。

> 2\.复杂度分析
> - 时间复杂度：$O(n^2)$，其中 $n$ 为点的数量，最坏情况下需要遍历所有点对。
> - 空间复杂度：$O(n)$，用于存储点的坐标。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
struct node{
	int x,y;
}a[20010];
int n,ans;
map<pair<int,int>,int> mp;
int main(){
	cin>>n;
	for(int i=1;i<=n;i++){
		cin>>a[i].x>>a[i].y;
		mp[{a[i].x,a[i].y}]=1;
	}
	for(int i=1;i<=n;i++){
		for(int j=1;j<=n;j++){
			if(mp[{a[i].x,a[j].y}]==1&&mp[{a[j].x,a[i].y}]==1&&a[i].x>a[j].x&&a[i].y>a[j].y) ans++;
		}
	}
	cout<<ans;
	return 0;
}
```
