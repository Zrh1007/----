# T637650 共同数位

## 简化题意

> 给定一个小于等于 $1000$ 的正整数 $x$，请找到最小的非负整数 $y$，使得数字 $x$ 和 $y$ 至少有一个共同的数位。

## 思路

> 1\. 规律
>
> - 我们发现 $y$ 如果要最小，那么 $y$ 只能是一位数。
> - 因此我们可以直接枚举 $x$ 的每一位数字，找到最小的数位。

> 2\. 实现
>
> - 我们可以使用一个循环来遍历 $x$ 的每一位数字，并记录下最小的数位。

> 3\. 复杂度分析
>
> - 时间复杂度：$O(n)$，其中 $n$ 是数字 $x$ 的位数。
> - 空间复杂度：$O(1)$，只使用了常数级别的额外空间。

## 代码实现

```cpp
#include<bits/stdc++.h> 
using namespace std;
string x;
int main(){
	ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
	cin>>x;
	char minn='9'+1;
	for(int i=0;i<x.size();i++){
		minn=min(minn,x[i]);
	}
	putchar(minn);
	return 0;
} 
```

# T637652 远足

## 简化题意

> 给定一个由 $n$ 个由 $0$ 和 $1$ 组成的数组 $a$ 和一个正整数 $k$，请找出一共有多少个长度为 $k$ 的不重复区间（每个区间必须要空一个元素）。

## 思路

> 1\. 规律
>
> - 我们可以使用一个循环来遍历数组 $a$，
> - 记录当前区间的起始位置和结束位置，判断是否满足条件。
> - 当满足条件时，下一次循环时需要将起始位置向后移动一位。

> 2\. 实现
>
> - 在遍历过程中，只需要从前向后扫描数组 $a$，找到所有满足条件的区间，所以不需要使用集合。
> - 记录当前区间的起始位置和结束位置，判断是否满足条件。
> - 当满足条件时，下一次循环时需要将起始位置向后移动一位。

> 3\. 复杂度分析
>
> - 时间复杂度：$O(n)$，其中 $n$ 是数组 $a$ 的长度。
> - 空间复杂度：$O(n)$，存储数组 $a$。

## 代码实现

```cpp
#include<bits/stdc++.h>
using namespace std;
int n,k;
bool a[100010]; 
int main(){
	ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
	cin>>n>>k;
	for(int i=1;i<=n;i++){
		cin>>a[i];
	}
	int cnt=0,op=1,sie=0;
	for(int i=1;i<=n;i++){
		if(op==2){
			op=1;
			continue;
		}
		if(a[i]==0&&op){
			op=0;
		}
		if(!op&&a[i]==0){
			sie++;
			if(sie==k) op=2,cnt++,sie=0;
		}
		if(!op&&a[i]==1){
			sie=0;
			op=1;
		}
	}
	cout<<cnt;
	return 0;
}
```

# T637845 快往上爬

## 简化题意

> 判断是否能从位置 $k$ 出发，经若干次耗时 $|h_i-h_j|$ 单位时间的传送，在每步出发位置 $i$ 的截止时间 $h_i-1$ 内是否能到达最大的位置。

## 思路

> 1\. 规律
>
> - 我们可以使用贪心算法，从后向前遍历每个位置，判断是否能到达最大的位置。

> 2\. 实现
>
> - 维护一个变量 `max_pos`，表示当前能到达的最大位置。
> - 从后向前遍历每个位置，如果当前位置的截止时间大于等于 `max_pos`，则更新 `max_pos`。

> 3\. 复杂度分析
>
> - 时间复杂度：$O(t \times (n+\log n))$，其中 $n$ 是数组的长度，$t$ 是测试用例的数量。
> - 空间复杂度：$O(n)$，存储数组 $a$。

## 代码实现

```cpp
#include<bits/stdc++.h> 
using namespace std;
int n,k,dis,a[100010];
void solve(){
	cin>>n>>k;
	for(int i=1;i<=n;i++){
		cin>>a[i];
	}
	dis=a[k];
	int now=a[k],f=1;
	sort(a+1,a+1+n);
	for(int i=1;i<=n;i++){
		if(a[i]<now) continue;
		if(a[i]-now>dis){
			f=0;
			break;
		}
		now=a[i];
	}
	if(f) cout<<"YES\n";
	else cout<<"NO\n";
}
int main(){
	ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
	int t;
	cin>>t;
	while(t--){
		solve();
	}
	return 0;
}
```
