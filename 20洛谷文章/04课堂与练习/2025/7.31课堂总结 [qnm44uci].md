## U408366 环数

### 题意简化
> 给定一个长度为n的环，求环上任意连续m个数字的和的最大值以及第一次出现最大值的位置。

### 思路
> 由于是环形结构，我们可以将其转化为一个长度为 $n \times 2$ 的数组，前 $n$ 个元素为原数组，后 $n$ 个元素为原数组的前 $n$ 个元素。这样就可以使用滑动窗口来求解。
> 滑动窗口的大小为 $m$ ，初始窗口为前 $m$ 个元素。然后将窗口向右滑动，每次将新元素加入窗口，同时移除最左边的元素。每次更新最大值和位置。
> 注意，当窗口滑动到原数组的后半部分时，需要将位置转换为原数组的索引。
> 时间复杂度为$O(n)$，空间复杂度为$O(n)$。

### 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
int t,n,m,a[100010];
long long sum[200010];
int main(){
	cin>>t;
	while(t--){
		cin>>n>>m;
		for(int i=1;i<=n;i++){
			cin>>a[i];
			sum[i]=sum[i-1]+a[i];// 计算前缀和
		}
		for(int i=1;i<=n;i++){
			sum[n+i]=sum[n+i-1]+a[i];// 将前n个元素复制到后半部分
		}
		long long maxn=-1e18,mr;
		for(int i=1;i+m-1<=2*n;i++){
			int l=i;
			int r=i+m-1;
			if(maxn<sum[r]-sum[l-1]) maxn=sum[r]-sum[l-1],mr=l;// 记录最大值和位置
		}
		cout<<maxn<<' '<<mr<<'\n';// 输出最大值和位置
	}
    return 0;
}
```

## U427199 书柜

### 题意简化
> 给定一个长度为n的序列，序列的元素有A和B两种类型。一共有t次询问，每次询问给定一个区间[l,r]，求该区间内A和B的最长严格上升子序列的开始位置和总和。

### 思路
> 我们可以发现，在序列中只有A和B两种元素，所以我们可以把小的替换成 $0$ ，大的替换成 $1$ ，但是由于子序列必须严格上升，所以我们可以发现，最长严格上升子序列的长度不是1就是2，由此可以得出判断公式$a_i=0$ && $a_i+1=1$,然后我们只需要利用前缀和和滑动窗口来求解即可，时间复杂度为$O(n)$，空间复杂度为$O(n)$，注意区间的边界。

### 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
int t;
int n,ha,hb;
bool a[5000010];
int sum[5000010];
string s;
int main(){
	cin>>n>>t;
	cin>>ha>>hb;
	cin>>s;
	if(ha==hb){
		while(t--){
			int l,r;
			cin>>l>>r;
			cout<<1<<'\n';
		}
		return 0;
	}
	for(int i=0;i<n;i++){
		if(s[i]=='A') a[i+1]=(ha>hb);// 将A替换为0或1
		else a[i+1]=(ha<hb);// 将B替换为0或1
	}
	for(int i=1;i<=n;i++) sum[i]=sum[i-1]+(a[i]==0&&a[i+1]==1);// 计算前缀和
	while(t--){
		int l,r;
		cin>>l>>r;
		r--;
		if(sum[r]-sum[l-1]==0){// 如果区间内没有严格上升子序列
			cout<<1<<'\n';
		}
		else cout<<2<<'\n';// 如果区间内有严格上升子序列
	}
    return 0;
}
```
