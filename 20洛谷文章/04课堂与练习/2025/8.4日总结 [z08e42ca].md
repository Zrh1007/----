# P1180 驾车旅游

## 简化题意
> 有一条长度为 $D$ 的路径。路径上有 $n$ 个补给点，每个补给点用 $(d_i, p_i)$ 表示：距起点 $d_i$，补给单价为 $p_i$。起点已满，初始费用为 $S$；每单位容量可行走 $L$ 距离；容量上限为 $C$；总费用取精确到 $0.1$。每次补给需额外支付 20。第一次补给时必须补满。若当前储量足以到达下一个补给点或终点，且剩余不少于容量的一半，则不会补给。 求到达终点所需的最小总费用。
---

## 思路
> 1. **贪心不可行**
>
>   * 仅按油价从低到高选择补给点，可能导致无法到达终点（因为距离与油量限制未考虑）。

> 2. **使用 DFS（带剪枝）**
>
>   * 在每个补给点考虑两种操作：
>
>     * **不加油**：若油量足以抵达下一个点且油量 ≥ 一半容量。
>     * **加满油**：若油量不足，或虽足够但 < 一半容量（允许选择加或不加）。
>   * 每次加油：费用 = 20 + (加的油量 × 单价)。
>   * 剪枝：若当前费用 > 已知最优解，直接回溯。

> 3. **状态维护**
>
>   * `oil`：当前油量。
>   * `cost`：累计费用。
>   * `cur`：当前所在补给点编号。
>
> 4. **终止条件**
>
>   * 抵达终点时更新最优解。

---

## 关键优化点

> * **最优性剪枝**：若当前费用超过历史最优，则不再搜索。
> * **容量与油耗换算**：距离差 ÷ $L$ → 所需油量。
> * **保证可达性**：若油量不足，则必须加满。

## 代码实现

```cpp
#include<bits/stdc++.h>
using namespace std;
const int maxn=1e5+7;
double dis;
int n;
double max_oil,mile,start,half;//max_oil:油量 mile:公里数 half:一半油量
struct node{
    double dis;//距离
    double fare;//花费
} a[maxn];
double ans=1e18;//初始化为一个很大的数
/*
    oil:当前油量
    cost:当前花费
    cur:当前加油站的id
*/
void dfs(double oil,double cost,int cur){
    if(cost>ans)//最优性剪枝，当前的答案已经超过出现过的答案
        return;
    if(cur==n+1){//到达最后一个加油站
        ans=min(cost,ans);
        return;
    }
   //判断以下能不能到达下一个加油站
    double tmp1=(a[cur+1].dis-a[cur].dis);
    double tmp2=tmp1/mile;
    if(oil*mile>=tmp1){//可以到下一站
        if(oil>=half){//多于一半不能在本站加油
            dfs(oil-tmp2,cost,cur+1);//不选
        } else{//可以加也可以不加
            dfs(oil-tmp2,cost,cur+1);
            dfs(max_oil-tmp2,cost+20+(max_oil-oil)*a[cur].fare,cur+1);//加油加满选
        }
    } else{//必须加
        dfs(max_oil-tmp2,cost+20+(max_oil-oil)*a[cur].fare,cur+1);
    }
    return;
}
int main(){
    cin>>dis;
    cin>>max_oil>>mile>>start;
    cin>>n;
    half=max_oil/2;//一半油量
    for(int i=1;i<=n;i++){
        cin>>a[i].dis>>a[i].fare;
    }
    a[n+1]={dis,0.0};//终点
    dfs(max_oil-(a[1].dis/mile),start,1);
    cout<<fixed<<setprecision(1);
    cout<<ans<<endl;
    return 0;
}
```
