# t637642 比较数字

## 简化题意
> 给定一个小于等于 $10^5000$ 的正整数 $a$ 且一定包含 $0$，请输出最小的那一个大于 $a$ 的没有 $0$ 的数字。

## 思路
> 1\. 规律
> - 找到第一个等于 $0$ 的数字，将其加 $1$，并将后面的数字都变成 $1$。
> - 由于 $a$ 一定包含 $0$，所以可以直接从左到右找到第一个 $0$，然后进行上述操作。
> 2\. 实现
> - 将 $a$ 转换成字符串，方便逐位处理。
> - 找到第一个 $0$ 的位置，将其加 $1$，并将后面的数字都变成 $1$。
> - 将处理后的字符串直接输出即可。
> 3\. 复杂度分析
> - 时间复杂度：$O(n)$，其中 $n$ 是数字 $a$ 的位数。
> - 空间复杂度：$O(n)$，存储处理后的字符串。

## 代码实现
```cpp
#include<bits/stdc++.h> 
using namespace std;
string s;
int op=1;
int main(){
	cin>>s;
	for(int i=0;i<s.size();i++){
		if(s[i]=='0') cout<<1,op=0;
		else if(op) cout<<s[i];
		else cout<<1;
	}
	return 0;
}
```

# t637627 张的弓

## 简化题意
> 在 $n * m$ 的点阵里，点 $A$ 从 $(1, 1)$ 出发，沿题意所示的方向进行弓形走位(**就是遇到右边界就会向上拐弯**)，问走到第 $k$ 步时的曼哈顿距离。

## 思路
> 1\. 规律
> - 观察走位的规律，可以发现每一列的走位都是相同的，只是行数不同。
> - 因此可以将问题转化为求第 $k$ 步时，点 $A$ 在第 $c$ 列的曼哈顿距离，其中 $c$ 为当前列数。
> 2\. 实现
> - 计算当前列数 $c$，即 $c=(k-1)/(2*n)+1$。
> - 计算当前行数 $r$，即 $r=k-(c-1)*2*n$。
> 3\. 复杂度分析
> - 时间复杂度：$O(k)$，其中 $k$ 为步数。
> - 空间复杂度：$O(k)$，存储每一步的坐标信息。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
int t,n,m,k;
int main(){
	ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
	cin>>t;
	while(t--){
		cin>>n>>m>>k;
		k=k-k/n*2*n*2;
		int x=1,y=2*k/n*2+1;
		for(int i=1;i<=k;i++){
			if(y%2==1){
				if(x!=n) x++;
				else y++;
			}
			else{
				if(x!=1) x--;
				else y++;
			}
		}
		cout<<(x-1)+(y-1)<<'\n';
	}
	return 0;
}
```

# T637602 可可口乐

## 简化题意
> 给定一个长度为 $8$ 的字符串 $s$，问经过几次交换可以将其变成 "cocacola"。

## 思路
> 1\. 规律
> - 我们可以使用BFS来搜索最少交换次数。
> 2\. 实现
> - 使用队列记录当前字符串状态和已交换次数。
> - 每次从队列中取出一个状态，尝试所有可能的交换，若得到新状态则加入队列。
> - 直到找到目标状态 "cocacola" 或队列为空。
> 3\. 状态维护
> - 使用集合记录已访问的状态，避免重复搜索。
> 4\. 复杂度分析
> - 时间复杂度：$O(n!)$，其中 $n$ 是字符串 $s$ 的长度。
> - 空间复杂度：$O(n!)$，存储所有可能的状态。

## 代码实现
```cpp
#include<bits/stdc++.h> 
using namespace std;
struct node{
	string s;
    int step; 
}; 
string S,T="cocacola"; 
map<string,bool> vis;
int bfs() {    
    queue<node> q;    
    q.push({S, 0});    
    vis[S] = 1;    
    while(!q.empty()){        
        node f=q.front();        
        q.pop();
        if(f.s==T) return f.step;                
        int pos=0;         
        for(int i=0;i<8;i++) if(f.s[i]!=T[i]){pos=i;break;}                       
        for (int i=pos+1;i<8;i++){            
            string ns=f.s;            
            swap(ns[pos], ns[i]);            
            if(!vis.count(ns)){                
                vis[ns]=1;                
                q.push({ns,f.step+1});            
            }        
        }    
    }    
    return -1; 
}
int main(){
	ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
	cin>>S;    
    cout<<bfs();
	return 0;
}
```
