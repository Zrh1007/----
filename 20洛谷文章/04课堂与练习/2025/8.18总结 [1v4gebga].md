# T638298 小明搭公交

## 简化题意
> 在 $N$ 辆公交车中，找出满足 $S\_i+T\_i \leq X$ 的最大 $S\_i$，若不存在则输出 $-1$。

## 思路
> 1\.模拟
> - 使用一个变量来记录当前的最大值。
> - 遍历每辆公交车，判断其上下车时间是否满足条件。
> - 更新最大值。  

> 2\.复杂度分析
> - 时间复杂度：$O(N)$，其中 $N$ 是公交车的数量。
> - 空间复杂度：$O(1)$，只使用了常数空间。  

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
long long x,n,maxn=-1;
int main(){
	cin>>n>>x;
	for(int i=1;i<=n;i++){
		long long l,r;
		cin>>l>>r;
		if(l+r<=x){
			maxn=max(l,maxn);
		}
	}
	cout<<maxn;
	return 0;
} 
```

# T638034 真实社交

## 简化题意
> 在一个 $N\times N$ 编号网格中，每个网络中的数为 $N \times (i-1) + j$ ，依次标记序列 $A_1,\dots,A_T$，求最小的 $k$ 使前 $k$ 步后出现某行、列或对角线全标记，否则输出 $-1$。

## 思路
> 1\.模拟
> - 使用一个二维数组来表示网格的标记状态。
> - 对于每个标记操作，更新相应的行、列和对角线的标记状态。
> - 在每次标记后检查是否有行、列或对角线全标记。
> - 时间复杂度：$O(N^2 + T)$，其中 $N^2$ 是初始化网格的时间，$T$ 是标记操作的数量，会爆。  

> 2\.优化
> - 使用"hang"、"lie"两个数组和"fx"、"zx"两个变量来记录每行、列和对角线的标记数量。
> - 在每次标记后更新这些状态，并检查是否有全标记的情况。  

> 3\.根据给定的数判断行和列
> - 我们发现行$i=(n - 1) \div x$，列$j=(n - 1) \mod x$，其中 $x$ 是标记的数。
> - 这样可以直接计算出标记所在的行和列，而不需要遍历整个网格。  

> 4\.复杂度分析
> - 时间复杂度：$O(N+T)$，其中 $N$ 是网格的大小，$T$ 是标记操作的数量。
> - 空间复杂度：$O(N)$，用于存储行、列和对角线的标记状态。  

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
int n,t;
int hang[2010],lie[2010],fx,zx;
int main(){
	cin>>n>>t;
	int b=t;
	while(t--){
		int k,x=0,y=0;
		cin>>k;
		hang[(k-1)/n+1]++;
		lie[(k-1)%n+1]++;
		if((k-1)%n+1==(k-1)/n+1){
			fx++;
		}
		if((k-1)/n+1+(k-1)%n+1==n+1){
			zx++;
		}
		for(int i=1;i<=n;i++){
			if(hang[i]==n||lie[i]==n){
				cout<<b-t;
				return 0;
			}
		}
		if(zx==n||fx==n){
			cout<<b-t;
			return 0;
		}
	}
	cout<<-1;
	return 0;
}
```

# T641930 长度为n的第k个排列

## 简化题意
> 求 $1, 2, 3, \dots , n$ 的字典序第 $k$ 小的全排列。

## 思路
> 1\.模拟（DFS）
> - 使用深度优先搜索（DFS）来生成全排列。
> - 在每次递归中，选择一个未使用的数字，并将其加入当前排列。
> - 当排列长度达到 $n$ 时，检查是否为第 $k$ 小的排列。
> - 如果是，则输出该排列并结束程序。  

> 2\.复杂度分析
> - 时间复杂度：$O(n!)$，其中 $n!$ 是全排列的数量。
> - 空间复杂度：$O(n)$，用于存储当前排列和标记数组。  

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
int n,k,cnt=0;
int vis[11],dis[11];
void dfs(int u){
	if(u>n){
		if(cnt==k-1){
			for(int i=1;i<=n;i++){
				cout<<vis[i]<<' ';
			}
			exit(0);
		} 
		else{
			cnt++;
			return;
		}
	}
	for(int i=1;i<=n;i++){
		if(dis[i]==0){
			dis[i]=1;
			vis[u]=i;
			dfs(u+1);
			dis[i]=0;
		}
	}
	return;
}
int main(){
	cin>>n>>k;
	dfs(1);
	return 0;
}
```
