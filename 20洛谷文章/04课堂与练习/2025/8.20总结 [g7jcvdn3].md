# T638414 营养达标

## 简化题意
> 给定数组 $A$ 和矩阵 $X$，判断 $X_i$ 每列的和是否满足对应的 $A_i$。

## 思路
> 1\.模拟  
> - 遍历每一列，计算其和并与对应的 $A_i$ 进行比较。
> - 如果某列的和小于对应的 $A_i$，则输出 "No" 并结束程序。
> - 如果所有列的和都满足条件，则输出 "Yes"。

> 2\.复杂度分析
> - 时间复杂度：$O(N \times M)$，其中 $N$ 是矩阵的行数，$M$ 是列数。
> - 空间复杂度：$O(n \times m + n)$，用于存储矩阵 $X$ 和数组 $A$。

## 代码实现
```cpp
#include<bits/stdc++.h> 
using namespace std;
int n,m,a[110],x[110][110]; 
int main(){
	cin>>n>>m;
	for(int i=1;i<=m;i++){
		cin>>a[i];
	}
	for(int i=1;i<=n;i++){
		for(int j=1;j<=m;j++){
			cin>>x[i][j];
		}
	}
	for(int i=1;i<=m;i++){
		int sum=0;
		for(int j=1;j<=n;j++){
			sum+=x[j][i];
		}
		if(sum<a[i]){
			cout<<"No";
			return 0;
		}
	}
	cout<<"Yes";
	return 0;
}
```

# T638487 打扫卫生

## 简化题意
> 给定一个二维 $n \times m$ 的 $0/1$ 矩阵（$1$ 表示脏 `*`，$0$ 表示干净 `.`）和一个整数 $k$，表示操作的方块大小。
> 每次可选择一个 $k \times k$ 的子矩阵，前提是该子矩阵全为 $1$。
> 操作后该子矩阵的所有元素都变为 $0$。操作耗时 $1$ 个单位时间。求最少操作次数使矩阵全为 $0$。若无解，输出 $-1$。

## 思路
> 1\.模拟
> - 遍历整个矩阵，找到所有的 $1$，并尝试用 $k \times k$ 的方块覆盖它们。
> - 每次找到一个合法的方块，就将其覆盖，并记录操作次数。
> - 如果无法覆盖所有的 $1$，则输出 $-1$。

> 2\.复杂度分析
> - 时间复杂度：$O(N \times M)$，其中 $N$ 是矩阵的行数，$M$ 是列数。
> - 空间复杂度：$O(n \times m + n)$，用于存储矩阵 $X$ 和数组 $A$。

## 代码实现
```cpp
#include<bits/stdc++.h> 
using namespace std;
long long n,m,k,cnt;
vector<char> s[200010];
int main(){
	cin>>n>>m>>k;
	for(int i=1;i<=n;i++){
		s[i].push_back('.');
		for(int j=1;j<=m;j++){
			char x;
			cin>>x;
			s[i].push_back(x);
		}
	}
	for(int i=1;i+k-1<=n;i++){
		for(int j=1;j+k-1<=m;j++){
			bool op=1;
			for(int f=i;f<=i+k-1;f++){
				for(int p=j;p<=j+k-1;p++){
					if(s[f][p]=='.'){
						op=0;
						break;
					}
				}
			}
			if(op){
				cnt++;
				for(int f=i;f<=i+k-1;f++){
					for(int p=j;p<=j+k-1;p++){
						s[f][p]='.';
					}
				}
			}
		}
	}
	for(int i=1;i<=n;i++){
		for(int j=1;j<=m;j++){
			if(s[i][j]=='*'){
				cout<<-1;
				return 0;
			}
		}
	}
	cout<<cnt;
	return 0;
}
```

# T643658 落落的去的数学题1

## 简化题意
> 给定 $a,b,c$ ，求 $2^a+2^b-2^c$ 结果二进制中 $1$ 的个数。

## 思路
> 1\.模拟
> - 计算 $2^a+2^b-2^c$ 的值。
> - 统计该值的二进制表示中 $1$ 的个数。
> - 时间复杂度：$O(\log(max(a,b,c)))$，其中 $max(a,b,c)$ 是 $a,b,c$ 中的最大值。
> - 数据范围：$1\leq c<b<a\leq 10^9$ 会爆。

> 2\.推导
> - 通过观察可以发现，$2^a+2^b-2^c$ 可以简化为 $2^a+\sum_{i=c}^{b-1}2^i$ 。
> - 所以它的二进制就是：在第 $a$ 位放一个 $1$，再加上一段从第 $c$ 位到第 $b-1$ 位的连续 $1$。
> - 因此，结果的二进制中 $1$ 的个数为 $b-c+1$。

> 3\.复杂度
> - 时间复杂度：$O(1)$。
> - 空间复杂度：$O(1)$。

## 代码实现
```cpp
#include<bits/stdc++.h> 
using namespace std;
int a,b,c;
int main(){
	cin>>a>>b>>c;
	cout<<b-c+1;
	return 0;
}
```
