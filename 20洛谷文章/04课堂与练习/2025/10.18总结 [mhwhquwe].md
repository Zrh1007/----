# P11853 [CSP-J2022 山东] 植树节

## 简化题意
>有n个志愿者，每人给编号在[a_i, b_i]区间内的树苗各浇1次水，求所有树苗中被浇水次数最多的次数。

## 思路
> 1\.模拟
> - 直接模拟每个志愿者的浇水操作，记录每棵树苗被浇水的次数。

> 2\.差分
> - 使用差分数组记录每个区间的增减变化。
> - 遍历所有操作，更新差分数组。

> 3\.复杂度分析
> - 时间复杂度：$O(n)$
> - 空间复杂度：$O(n)$

## 代码实现
```cpp
#include <bits/stdc++.h>
using namespace std;
int s[1000010],n,a,b,sum,c;
signed main(){
    cin>>n;
    for(int i=1;i<=n;i++){
        cin>>a>>b;
        s[a+1]++;
        s[b+2]--;
    }
    for(int i=1;i<=1000000;i++){
        c+=s[i];
        sum=max(sum,c);
    }
    cout<<sum;
    return 0;
}

```
