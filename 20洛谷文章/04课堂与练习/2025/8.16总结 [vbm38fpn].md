# T637945 落落的去的宇宙

## 简化题意
> 第一行一个整数 $t$ 表示测试用例数量。接下来的 $t$ 行，每行包含三个用空格分隔的小写字符串。
> 对每个测试用例，输出由该行每个字符串的首字母组成的字符串。

## 思路
> 1\.思路
> - 读取测试用例数量 $t$ 。
> - 对于每个测试用例，读取三个字符串并提取首字母。
> 2\.实现
> - 使用一个循环遍历每个测试用例。
> - 对于每个测试用例，使用 `cin` 读取三个字符串。
> - 使用 `string` 的 `substr` 方法提取首字母并拼接成结果字符串。
> - 最后输出结果字符串。
> 3\.复杂度分析
> - 时间复杂度：$O(t)$，其中 $t$ 是测试用例数量。
> - 空间复杂度：$O(s1+s2+s3)$，其中 $s1$、$s2$ 和 $s3$ 分别是三个字符串的长度。

## 代码实现
```cpp
#include<bits/stdc++.h> 
using namespace std;
int t;
int main(){
	cin>>t;
	while(t--){
		string s[3];
		cin>>s[0];
		getchar();
		cin>>s[1];
		getchar();
		cin>>s[2];
		cout<<s[0][0]<<s[1][0]<<s[2][0]<<'\n';
	}
	return 0;
}
```

# T637925 敲鼓

## 简化题意
> 给定两个字符串 $p$ 和 $s$，每个字符可以重复一次或两次。判断 $s$ 是否可以由 $p$ 生成，即：
> 对于 $p = p_1 p_2 \dots p_n$ 中的每个字符 $p_i$，它在 $s$ 中对应连续出现一次或两次；
> 且 $s$ 的顺序必须与 $p$ 保持一致。


## 思路
> 1\. 贪心不可行
> - 首先，考虑到字符的重复性，贪心策略可能无法找到最优解。
> 2\.搜索（DFS）
> - 将问题转化为一个深度优先搜索（DFS）问题，尝试在 $s$ 中找到 $p$ 的匹配。
> - 使用递归函数，遍历 $p$ 和 $s$ 的每个字符，尝试匹配。
> - 如果当前字符匹配，则继续匹配下一个字符。
> - 如果不匹配，则尝试跳过 $s$ 中的一个字符。
> - 如果找到匹配，则返回成功。
> - 时间复杂度: $O(n \cdot m)$，其中 $n$ 是 $p$ 的长度，$m$ 是 $s$ 的长度。会超时。
> 3\.统计相同字母区间
> - 首先统计 $p$ 和 $s$ 中每个字符的连续出现次数。
> - 然后比较 $p$ 中每个字符的出现次数与 $s$ 中对应字符的出现次数，如果 $s$ 中的次数小于 $p$ 中的次数或者区间数量不一样或 $s$ 的长度$\times2$小于$p$ 的长度，则说明 $s$ 不能由 $p$ 生成。否则输出“Yes”。

## 代码实现
```cpp
#include<bits/stdc++.h> 
using namespace std;
int t;
string s1,s2;
void solve(){
	cin>>s1>>s2;
	if(s1.size()>s2.size()||s1.size()*2<s2.size()||s1[0]!=s2[0]){
		cout<<"No\n";
		return;
	}
	vector<int> a; 
	vector<int> b; 
	int cnt=1;
	for(int i=1;i<s1.size();i++){
		if(s1[i]==s1[i-1]) cnt++;
		else a.push_back(cnt),cnt=1;
	}
	a.push_back(cnt);
	cnt=1;
	for(int i=1;i<s2.size();i++){
		if(s2[i]==s2[i-1]) cnt++;
		else b.push_back(cnt),cnt=1;
	}
	b.push_back(cnt);
	if(a.size()!=b.size()){
		cout<<"No\n";
		return;
	}
	for(int i=0;i<b.size();i++){
		if(a[i]>b[i]||a[i]*2<b[i]){
			cout<<"No\n";
			return;
		}
	}
	cout<<"Yes\n";
}
int main(){
	cin>>t;
	while(t--){
		solve();
	}
	return 0;
}
```

# T637889 箭头路径

## 简化题意
> 给定一个 \$2 \times n\$ 网格，每个单元格含箭头（'<' 或 '>'），箭头只指向左右格子，不会指向网格外。
> 机器人从 \$(1,1)\$ 出发，每步先向上下左右移动一步（不能出界），然后沿箭头自动移动到相邻单元格。
> 判断机器人能否到达 \$(2,n)\$。

## 思路
> 1\.使用搜索（DFS）
> - 使用深度优先搜索（DFS）遍历网格，记录访问过的状态。
> - 从起始位置 \$(1,1)\$ 开始，尝试所有可能的移动方向。
> - 如果到达目标位置 \$(2,n)\$，则返回成功。
> 2\.实现
> - 使用一个栈来实现DFS，记录当前的位置和访问状态。
> - 在每一步中，尝试向上下左右移动，并根据箭头的方向移动到相邻单元格。
> - 如果找到一条可行路径，则返回成功。

## 代码实现
```cpp
#include<bits/stdc++.h> 
using namespace std;
char a[3][100010]; 
int n, flag; 
bool vis[3][100010]; 
int dx[4] = {1, -1, 0, 0}; 
int dy[4] = {0, 0, 1, -1};
void dfs(int x, int y) {    
	if (x == 2 && y == n){        
		flag = 1;        
		return;    
	}    
	for(int i = 0; i < 4; i++){        
		int xx = x + dx[i], yy = y + dy[i];        
		if (xx>=1 && xx<=2 && yy>=1 && yy<=n && vis[xx][yy]==0){            
			vis[xx][yy] = 1;
			if(a[xx][yy]=='>') yy+=1; 
			else yy-=1;            
			if (yy<1 || yy>n) continue;            
			dfs(xx, yy);        
		}    
	} 
}
void solve(){
	flag = 0;        
	memset(vis, 0, sizeof vis);         
	cin >> n;        
	for (int i = 1; i <= 2; i++) for (int j = 1; j <= n; j++) cin >> a[i][j];                
	vis[1][1] = 1;        
	dfs(1, 1);        
	if (flag) cout << "YES\n";        
	else cout << "NO\n";
}
int main(){
	int t;
	cin>>t;
	while(t--){
		solve();
	}
	return 0;
}

```
