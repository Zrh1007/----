# U593635 交换

## 简化题意
> 给定正整数 $a,b,c$ 请输出交换 $a$ 和 $b$ 然后交换 $a$ 和 $c$ 的结果。


## 思路
> 1\.模拟
> - 我们可以发现交换完成后，$a$ 的值为 $c$，$b$ 的值为 $a$，$c$ 的值为 $b$。

> 2\.复杂度分析
> - 时间复杂度：$O(1)$，只需要常数时间进行交换。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
int x,y,z;
int main(){
	cin>>x>>y>>z;
	cout<<z<<' '<<x<<' '<<y;
	return 0;
} 
```

# T643661 猜猜芭蕾舞剧将如何结束

## 简化题意
> 在区间 $[0,R]$ 内，如果所有可能初始位置经过给定的 $N$ 次移动（遇边界停下）后最终来到同一个点，则输出该点，否则输出 $-1$。

## 思路
> 1\. 模拟
> - 我们发现可以不用枚举每一个出发点，而是可以给定两个极端出发点 $0$ 和 $r$ ，只要判断它们经过 $n$ 次移动后是否相等即可。

> 2\. 复杂度分析
> - 时间复杂度：$O(n)$，只需要遍历 $n$ 次。
> - 空间复杂度：$O(1)$，只需要常数空间。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
int r,n;
int main(){
	cin>>r>>n;
	int L=0,R=r;
	for(int i=1;i<=n;i++){
		int x;
		cin>>x;
		if(L+x<0){
			L=0;
		}
		else if(L+x>r){
			L=r;
		}
		else{
			L+=x;
		}
		if(R+x<0){
			R=0;
		}
		else if(R+x>r){
			R=r;
		}
		else{
			R+=x;
		}
	}
	if(L==R) cout<<L;
	else cout<<-1;
	return 0;
} 
```

# U593646 落落的去的数学问题五

## 简化题意
> 定义一个完美数是指这个数任意相邻两位的差的绝对值不超过 $1$ 。
> 请输出第 $k$ 个完美数。

## 思路
> 1\.模拟
> - 我们可以直接使用一个循环每次判断 $i$ 的相邻两位的差是否满足条件，如果满足条件则计数器加一；
> - 如果计数器等于 $k$，则输出当前的 $i$。
> - 时间复杂度：$O(n \cdot m)$，其中 $n$ 是完美数的个数，$m$ 是每个完美数的位数，会爆。

> 2\.优化（BFS）
> - 我们发现完美数可以通过搜索的方式产生，即每次在当前数的末尾添加一个与末尾数字差的绝对值不超过 $1$ 的数字。
> - 因此我们可以使用广度优先搜索（BFS）来生成完美数。
> - 每次从队列中取出一个数，然后在其末尾添加一个与末尾数字差的绝对值不超过 $1$ 的数字，形成新的数并加入队列。

> 3\.复杂度分析
> - 时间复杂度：$O(n)$，其中 $n$ 是完美数的个数。
> - 空间复杂度：$O(n)$，用于存储队列。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
int k,step;
long long bfs(){
	queue<long long> q;
	for(int i=1;i<=9;i++){
		q.push(i);
	}
	while(1){
		long long f=q.front();
		q.pop();
		step++;
		if(step==k){
			cout<<f;
			exit(0);
		}
		int f1,f2;
		if((f%10)-1>=0) f1=(f%10)-1;
		else f1=0;
		if((f%10)+1<=9) f2=(f%10)+1;
		else f2=9;
		for(int i=f1;i<=f2;i++){
			q.push(f*10+i);
		}
	}
}
int main(){
	cin>>k;
	bfs();
	return 0;
} 
```

# U593645 操作2

## 简化题意
> 给定一个数组 $a$ 和 $q$ 次询问，每次求自然数 $k$ 与数组中每个元素的绝对差值之和。

## 思路
> 1\.模拟
> - 对于每次询问，遍历一遍数组，将绝对差值加起来，然后输出结果。
> - 时间复杂度：$O(n \times q)$，主要是遍历数组的时间复杂度。

> 2\.优化
> - 我们可以通过预处理数组的前缀和来加速每次询问的计算。
> - 具体来说，我们可以维护一个前缀和数组 $s$，其中 $s[i]$ 表示数组 $a$ 中前 $i$ 个元素的和。
> - 这样，对于每次询问，我们可以通过 $s$ 数组快速计算出绝对差值之和。

> 3\.复杂度分析
> - 时间复杂度：$O(n)$，主要是预处理前缀和的时间复杂度。
> - 空间复杂度：$O(n)$，用于存储前缀和数组。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
long long n,q,a[200010],x,s[200010];
int main(){
	cin>>n>>q;
	for(int i=1;i<=n;i++) cin>>a[i];
	sort(a+1,a+1+n);
	for(int i=1;i<=n;i++) s[i]=s[i-1]+a[i];
	while(q--){
		cin>>x;
		int l=lower_bound(a+1,a+1+n,x)-a-1;
		int r=upper_bound(a+1,a+1+n,x)-a;
		long long ans=0;
		if(l!=0) ans+=l*x-s[l];
		if(r!=n+1) ans+=s[n]-s[r-1]-(n-r+1)*x;
		cout<<ans<<'\n';
	}
	return 0;
}
```
