# CF1006C Three Parts of the Array

## 简化题意
> 给定一个数组，要求将其分成三部分，使得每部分的和相等。求是否存在这样的分法。

## 思路
> 首先我们可以计算出数组的总和，如果总和不能被3整除，则不可能分成三部分。
> 然后使用前缀和数组，找到两个分界点，使得三部分的和相等。
> 具体地，我们可以使用二分查找来找到第二个分界点的位置。
## 代码
```cpp
#include<bits/stdc++.h>
using namespace std;
int a[200010],n;
long long sum[200010],ans;
int main(){
	cin>>n;
	for(int i=1;i<=n;i++){
		int x;
		cin>>x;
		sum[i]=sum[i-1]+x;
	}
	for(int i=1;i<=n;i++){
		int l=i+1;
		int r=n;
		int pos=lower_bound(sum+1,sum+n+1,sum[r]-sum[l-1])-sum;
		if(pos>=i&&sum[pos]==sum[r]-sum[l-1]){
			ans=sum[i];
		}
	}
	cout<<ans;
	return 0;
} 
```

# CF1041D Glider

## 简化题意
> 给定高度 $h$ 和 $n$ 个不重叠区间 $[x_1,x_2]$，从任意整数 $x$ 坐标出发，每步横坐标 $+1$，若不在区间内高度 $−1$，在区间内高度不变；高度降至 $0$ 时停止，求最大横坐标增量。

## 思路
> 我们可以使用前缀和数组来记录每个位置的高度变化情况。
> 然后遍历每个位置，计算从该位置出发的最大横坐标增量。
> 具体地，我们可以使用二分查找来找到第一个高度降至 $0$ 的位置。

## 代码
```cpp
#include<bits/stdc++.h>
using namespace std;
int n,k;
int s[200010],e[200010],sum[200010],ans[200010];
int main(){
	cin>>n>>k;
	for(int i=1;i<=n;i++){
		cin>>s[i]>>e[i];
		if(i>1) sum[i]=sum[i-1]+(s[i]-e[i-1]);
		ans[i]=ans[i-1]+(e[i]-s[i]);
	}
	int res=0;
	for(int i=1;i<=n;i++){
		int pos=lower_bound(sum+i+1,sum+1+n,k+sum[i])-sum;
		--pos;
		res=max(res,(ans[pos]-ans[i-1]));
	}
	cout<<res+k;
	return 0;
}
```

# CF1915E Romantic Glasses

## 简化题意
> 给定一个长度为 $n$ 的数组 $a$。判断是否存在一个连续子数组 $[l,r]$，使得子数组中奇数位置元素的和 = 偶数位置元素的和（位置编号从 $1$ 开始计算）。

## 思路
> 我们可以使用前缀和数组来记录奇数位置和偶数位置的和。
> 然后遍历前缀和数组，检查是否存在相同的差值。
> 如果存在相同的差值，则说明存在满足条件的子数组。

## 代码
```cpp
#include<bits/stdc++.h>
using namespace std;
int n,k;
long long a[500010];
long long sum1[500010];
long long sum2[500010];
map<long long,int> cnt;
int main(){
	int t;
	cin>>t;
	while(t--){
		int n;
		cin>>n;
		for(int i=1;i<=n;i++){
			cin>>a[i];
			if(i%2==1){
				sum1[i]=sum1[i-1]+a[i];
				sum2[i]=sum2[i-1]+0;
			}
			if(i%2==0){
				sum1[i]=sum1[i-1]+0;
				sum2[i]=sum2[i-1]+a[i];
			}
		}
		bool f=1;
		for(int r=0;r<=n;r++){
			cnt[sum1[r]-sum2[r]]++;
			if(cnt[sum1[r]-sum2[r]]>1){
				cout<<"YES\n";
				f=0;
				break;
			}
		}
		if(f) cout<<"NO\n";
		cnt.clear();
	}
	return 0;
}
```
