# T640710 高铁线路

## 简化题意
> 判断整数 $Z$ 是否在从 $X$ 到 $Y$ 的连续整数序列中，输出 `Yes` 或 `No`。

## 思路
> 1\.模拟
> - 遍历从 $X$ 到 $Y$ 的所有整数，判断 $Z$ 是否在其中。

> 2\.复杂度分析
> - 时间复杂度：$O(n)$，其中 $n$ 是从 $X$ 到 $Y$ 的整数个数。
> - 空间复杂度：$O(1)$。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
int n,x,y,z;
int main(){
	cin>>n>>x>>y>>z;
	if(x>z&&z>y){
		cout<<"Yes";
	}
	else if(y>z&&z>x){
		cout<<"Yes";
	}
	else{
		cout<<"No";
	}
	return 0;
} 
```

# T657893 Peter 的烟

## 简化题意
> 给定初始数量 $n$ 和兑换比例 $k>1$，每消费一个产生一个残值，每 $k$ 个残值可换一个新单位，求最终总可消费单位数。

## 思路
> 1\. 推导
> - 每消费一个单位，产生一个残值，总残值为 $n$。
> - 每 $k$ 个残值可换一个新单位，因此可以兑换的单位数为 $\lfloor \frac{n}{k} \rfloor$。
> - 由于每消费一个单位又会产生一个残值，因此总可消费单位数为 $n + \lfloor \frac{n}{k} \rfloor$。
> - 继续兑换，直到无法再兑换为止。

> 2\. 复杂度分析
> - 时间复杂度：$O(1)$。
> - 空间复杂度：$O(1)$。

## 代码实现
```cpp
#include <bits/stdc++.h>
using namespace std;
int main(){
    int n,k;
    cin>>n>>k;
    cout<<n+(n-1)/(k-1);
    return 0;
}
```

# T639117 Int128 游乐园

## 简化题意
> 给定容量为 $k$ 的容器和团体人数序列 $a_1,\dots,a_n$，依次放入，若当前团体人数超过剩余容量则重置容量一次，求总共重置次数。

## 思路
> 1\. 模拟
> - 遍历团体人数序列，对于每个团体，判断其人数是否超过剩余容量。
> - 如果超过，则重置容量，并记录重置次数。

> 2\.复杂度分析
> - 时间复杂度：$O(n)$，其中 $n$ 是团体人数序列的长度。
> - 空间复杂度：$O(1)$。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
queue<int> q;
int n,k;
int main(){
	cin>>n>>k;
	for(int i=1;i<=n;i++){
		int x;
		cin>>x;
		q.push(x);
	} 
	int cnt=1,box=k;
	while(q.size()){
		if(q.front()>box){
			cnt++;
			box=k;
		}
		else{
			box-=q.front();
			q.pop();
		}
	}
	cout<<cnt;
	return 0;
} 
```
