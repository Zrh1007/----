# T637969 转变

## 简化题意
> 给定一个数组 $a$ 和两个整数 $n$ 和 $k$，其中 $n$ 是数组的长度，$k$ 是要转变的次数。每次转变将数组的第一个元素移除，并在末尾添加一个 $0$。请输出转变后的数组。

## 思路
> 1\.模拟
> - 使用一个队列来存储数组元素。
> - 进行 $k$ 次转变，每次将队列的头部元素移除，并在尾部添加一个 $0$。

> 2\.维护
> - 使用一个循环进行 $k$ 次转变。

> 3\.复杂度分析
> - 时间复杂度：$O(n + k)$，其中 $n$ 是数组的长度，$k$ 是转变的次数。
> - 空间复杂度：$O(n)$，用于存储队列中的元素。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
queue<int> a;
int n,k;
int main(){
	cin>>n>>k;
	for(int i=1;i<=n;i++){
		int k;
		cin>>k;
		a.push(k);
	}
	for(int i=1;i<=k;i++){
		a.pop();
		a.push(0);
	}
	while(a.size()){
		cout<<a.front()<<' ';
		a.pop();
	}
	return 0;
} 
```

# T638034 真实社交

## 简化题意
> 给定一个有 $n$ 个节点的有向图，再给定 $Q$ 个查询，每个查询包含一个正整数 $op$ ，如果 $op==1$ 则添加一条边，如果 $op==2$ 则删除一条边，如果 $op==3$ 则查询两个节点之间是否有互相边。

## 思路
> 1\.邻接表模拟
> - 使用一个邻接表来存储图的边。
> - 对于每个查询，根据操作类型进行相应的图操作。
> - 时间复杂度：$O(Q*log(n))$ 会爆。

> 2\.map+pair模拟
> - 使用一个 $map$ 来存储边的状态，key 为一个pair类型，用来表示边的两个节点，value 为边的存在状态。
> - 对于查询 $3$ 使用 `mp.count({a,b})` 和 `mp.count({b,a})` 来判断两个节点之间是否有互相边。

> 3\.复杂度分析
> - 时间复杂度：$O(Q)$，其中 $Q$ 是查询的数量。
> - 空间复杂度：$O(Q)$，用于存储图的边。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
int n,q;
map<pair<int,int>,int> mp;
int main(){
	cin>>n>>q;
	while(q--){
		int op,a,b;
		cin>>op;
		cin>>a>>b;
		if(op==1){
			mp[{a,b}]=1;
		}
		else if(op==2){
			if(mp.count({a,b})) mp.erase({a,b});
		}
		else{
			if(mp.count({a,b})&&mp.count({b,a})) cout<<"Yes\n";
			else cout<<"No\n";
		}
	}
	return 0;
} 
```

# T638156 落落的去维护数组

## 简化题意
> 给定一个数组，每次询问给定一个正整数 $op$ 。  
> 如果 $op==1$ 则输入一个整数 $k$ 并将数组里的所有元素变成 $k$ ；  
> 如果 $op==2$ 则输入 $i$ 和 $k$ ，然后将 $a_i=a_i+k$；  
> 如果 $op==3$ 则输入 $i$ ，输出 $a_i$。  

## 思路
> 1\.模拟
> - 使用一个变量来记录当前的值。
> - 对于每个操作，根据操作类型进行相应的数组操作。
> - 时间复杂度：$O(p(op=1)\times n)$，其中 $p(op=1)$ 是操作 $1$ 的次数，$n$ 是数组的长度,不难发现会爆。

> 2\.优化
> - 使用 $lasttime$ 变量来记录上一次整体操作的时间，$lastval$ 变量来记录上一次整体操作的值。
> - 使用 $t_i$ 变量来记录每个元素的时间戳。
> - 使用 $a_i$ 变量来记录每个元素的增加量。

> 3\.复杂度分析
> - 时间复杂度：$O(Q)$，每个操作只需要常数时间。
> - 空间复杂度：$O(n \times 2)$，用于存储数组元素和时间戳。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
vector<long long> a;
int lasttime,lastval;
int t[200010];
int n,q;
int main(){
	cin>>n;
	for(int i=1;i<=n;i++){
		int x;
		cin>>x;
		a.push_back(x);
	}
	cin>>q;
	for(int wssb=1;wssb<=q;wssb++){
		long long op,x,k;
		cin>>op;
		if(op==1){
			cin>>k;
			lasttime=wssb;
			lastval=k;
		}
		else if(op==2){
			cin>>x>>k;
			if(t[x-1]<lasttime) a[x-1]=k;
			else a[x-1]+=k;
			t[x-1]=wssb;
		}
		else{
			cin>>x;
			if(t[x-1]<lasttime) cout<<lastval<<'\n';
			else cout<<a[x-1]+lastval<<'\n';
		}
	}
	return 0;
} 
```
