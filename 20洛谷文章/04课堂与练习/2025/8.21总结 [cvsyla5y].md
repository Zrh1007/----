# T639096 落落的去养植物

## 简化题意
> 求最小整数 $i$，使得 $2^{\sum_{1}^{i}} - 1 > H$。
## 思路
> 1\.模拟  
> - 计算 $2^{\sum_{1}^{i}} - 1$ 的值。
> - 判断该值是否大于 $H$。
> - 如果大于，则输出当前的 $i$ 值。
> - 否则，继续增加 $i$ 的值，直到找到满足条件的 $i$。

> 2\.复杂度分析
> - 时间复杂度：$O(\log H)$。
> - 空间复杂度：$O(1)$。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
long long h;
int main(){
	cin>>h;
	int cnt=0;
	long long h1=1,s=2;
	while(h1<=h){
		cnt++;
		h1+=s;
		s*=2;
	}
	cout<<cnt+1;
	return 0;
}
```

# T638487 打扫卫生

## 简化题意
> 存储一个 $\sum_{0}^{n}$ 的数字，需要的二进制数字长度是多少。  

## 思路
> 1\.模拟  
> - 计算 $\sum_{0}^{n}$ 的值。
> - 将该值转换为二进制表示，统计其长度。

> 2\.复杂度分析
> - 时间复杂度：$O(\log n)$。
> - 空间复杂度：$O(1)$。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
int n;
int main(){
	cin>>n;
	long long cnt=0;
	for(int i=0;i<=n;i++){
		string s="";
		int x=i;
		if(x==0){
			cnt++;
			continue;
		}
		while(x>0){
			s=char(x%2+'0')+s;
			x/=2;
		}
		cnt+=s.size();
	}
	cout<<cnt;
	return 0;
}
```

# T638482 小梦的铁索连环

## 简化题意
> 求图中权值和最大的完全子图（最大权团）的点权和。

## 思路
> 1\.模拟
> - 遍历所有的点，尝试以每个点为中心，扩展出一个完全子图。
> - 在扩展的过程中，维护当前子图的点权和，并更新最大权和。
> - 时间复杂度：$O(n^2)$，其中 $n$ 是图中点的数量，会爆。

> 2\.优化
> - 如果在加入新点时，新点与当前子图的所有点都有边相连，则可以直接将新点加入当前子图。

> 3\.复杂度
> - 时间复杂度：$O(\log n)$，其中 $n$ 是图中点的数量。
> - 空间复杂度：$O(n)$，用于存储图的邻接矩阵和点的状态。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
int n,m,a[455],box[455];
long long cnt;
bool dis[455][455],vis[455];
void dfs(int step,long long sum){
	cnt=max(cnt,sum);
	for(int i=1;i<=n;i++){
		if(vis[i]==0){
			bool f=1;
			for(int j=1;j<step;j++){
				if(dis[i][box[j]]==0){
					f=0;
					break;
				}
			}
			if(f){
				vis[i]=1;
				box[step]=i;
				dfs(step+1,sum+a[i]);
				vis[i]=0;
			}
		}
	}
	return;
}
int main(){
	cin>>n>>m;
	for(int i=1;i<=n;i++){
		int x;
		cin>>x;
		a[i]=x;
	}
	while(m--){
		int l,r;
		cin>>l>>r;
		dis[l][r]=dis[r][l]=1;
	}
	dfs(1,0);
	cout<<cnt;
	return 0;
}
```
