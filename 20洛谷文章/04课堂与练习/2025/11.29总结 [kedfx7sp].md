# P1536 村村通

## 题意简化
> 给定一个无向图，求使得图连通所需的最少边数。

## 题解
> 1.并查集
> - 使用并查集维护连通块的数量，最后输出连通块数量减一即为所需边数。

> [!success]+ 并查集代码
>
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> const int maxn=1005;
> int fa[maxn];
> int findfa(int x){return fa[x]==x?x:fa[x]=findfa(fa[x]);}
> void unite(int x,int y){
>     int fx=findfa(x),fy=findfa(y);
>     if(fx!=fy)fa[fx]=fy;
> }
> int main(){
>     int n,m;
>     while(1){
>         cin>>n;
>         if(n==0) break;
>         cin>>m;
>         for(int i=1;i<=n;i++)fa[i]=i;
>         int x,y;
>         for(int i=1;i<=m;i++){
>             cin>>x>>y;
>             unite(x,y);
>         }
>         int cnt=0;
>         for(int i=1;i<=n;i++)if(findfa(i)==i)cnt++;
>         cout<<cnt-1<<"\n";
>     }
>     return 0;
> }
> ```


> [!success]+ 时间复杂度
>
> - 时间复杂度：$O(n+m)$。

# T703065 无向图判环

## 题意简化
> 给定一个 n(<=10000) 个点 m(<=10000) 条边的无向图，请你判断这个无向图有没有环。

## 题解
> 1.并查集
> - 使用并查集维护连通块的数量，在合并时判断两个点是否已经在同一集合中，若是则存在环。

> [!success]+ 并查集代码
>
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> int t,p[10010];
> int find(int x){
> 	if(p[x]==x) return x;
> 	else return p[x]=find(p[x]);
> }
> void merge(int x,int y){
> 	int x1=find(x),y1=find(y);
> 	p[x1]=p[y1];
> }
> int main(){
>     ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
>     cin>>t;
>     while(t--){
>         int n,m,f=0;
>         cin>>n>>m;
>         fill(p,p+1+10005,0);
>         for(int i=1;i<=n;i++){
>             p[i]=i;
>         }
>         for(int i=1;i<=m;i++){
>             int x,y;
>             cin>>x>>y;
>             if(find(x)==find(y)) f=1;
>             merge(x,y);
>         }
>         if(f) cout<<"Yes\n";
>         else cout<<"No\n";
>     }
>     return 0;
> }
> ```


> [!success]+ 时间复杂度
>
> - 时间复杂度：$O(n+m)$。
