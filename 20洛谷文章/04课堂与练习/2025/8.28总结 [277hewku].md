# U593675 查找数

## 简化题意
> 给定 $A,B$，在 $C$ 集合中找到 $A+B$。输出其编号。


## 思路
> 1\.模拟
> - 首先遍历集合 $C$，找到 $A+B$ 的位置并输出。

> 2\.复杂度分析
> - 时间复杂度：$O(n)$，只需要遍历一次集合 $C$。
> - 空间复杂度：$O(1)$，只需要常数空间。

## 代码实现
```cpp
#include<bits/stdc++.h> 
using namespace std;
int n,a,b;
int main(){
	cin>>n>>a>>b;
	int f=n;
	while(n--){
		int x;
		cin>>x;
		if(x==a+b){
			cout<<f-n;
			return 0;
		}
	}
	return 0;
}
```

# U593858 数叉叉

## 简化题意
> 在一个 $h\times w$ 的网格中，所有 `#` 都组成若干不相交的对角线“叉叉”，求每个可能大小 $n$ 的叉叉个数 $S_n$。

## 思路
> 1\. 模拟
> - 首先遍历整个网格，对于每个 `#`，尝试以其为中心向外扩展，找到最大的叉叉。

> 2\. 复杂度分析
> - 时间复杂度：$O(h \times w \times \min(h,w))$，最坏情况下需要遍历整个网格并尝试扩展每个 `#`。
> - 空间复杂度：$O(h \times w)$，用于存储网格和访问标记。

## 代码实现
```cpp
#include<bits/stdc++.h> 
using namespace std;
int h,w,s[110],n;
char c[110][110];
bool vis[110][110];
int dfs(int x,int y){
	int d=1;
	while(1){
		if(c[x+d][y+d]=='#'&&c[x+d][y-d]=='#'&&c[x-d][y+d]=='#'&&c[x-d][y-d]=='#'){
			d++;
			vis[x+d][y+d]=vis[x+d][y-d]=vis[x-d][y+d]=vis[x-d][y-d]=1;
		}
		else return d-1;
	}
}
int main(){
	cin>>h>>w;
	n=min(h,w);
	for(int i=1;i<=h;i++){
		for(int j=1;j<=w;j++){
			cin>>c[i][j];
		}
	}
	for(int i=1;i<=h;i++){
		for(int j=1;j<=w;j++){
			if(vis[i][j]!=1&&c[i][j]=='#'){
				s[dfs(i,j)]++;
			}
		}
	}
	for(int i=1;i<=n;i++){
		cout<<s[i]<<' ';
	}
	return 0;
}
```

# T661095 结算日

## 简化题意
> 给定一条线上 \$N\$ 个点及每点的债务 \$D\_i\$，从 \$0\$ 出发资金为 \$0\$，需在保证随时能还清欠债的前提下走到 \$N\$，求最短行走距离。

## 思路
> 1\.模拟
> - 我们可以发现，从 \$0\$ 出发，资金为 \$0\$，在每个点 \$i\$ 处需要支付的债务为 \$D\_i\$，因此在到达点 \$i\$ 之前，必须至少有 \$D\_i\$ 的资金。
> - 因此，我们可以维护一个变量 \$cur\$ 表示当前的资金，初始为 \$0\$，然后遍历每个点，更新 \$cur\$ 的值。
> - 如果在到达某个点时，\$cur\$ 的值小于 \$D\_i\$，则说明无法还清债务，需要增加资金。
> - 最终的结果就是所有点的 \$D\_i\$ 的最大值。

> 2\.复杂度分析
> - 时间复杂度：\$O(N)\$，需要遍历所有点。
> - 空间复杂度：\$O(1)\$，只需要常数空间。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
int k,step;
long long bfs(){
	queue<long long> q;
	for(int i=1;i<=9;i++){
		q.push(i);
	}
	while(1){
		long long f=q.front();
		q.pop();
		step++;
		if(step==k){
			cout<<f;
			exit(0);
		}
		int f1,f2;
		if((f%10)-1>=0) f1=(f%10)-1;
		else f1=0;
		if((f%10)+1<=9) f2=(f%10)+1;
		else f2=9;
		for(int i=f1;i<=f2;i++){
			q.push(f*10+i);
		}
	}
}
int main(){
	cin>>k;
	bfs();
	return 0;
} 
```
