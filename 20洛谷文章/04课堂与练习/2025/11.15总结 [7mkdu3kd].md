## T692108 落落的凑钱问题 1

### 题意简化
> - 求 $t$ 有多少种方案可以由若干个 $1$ 和若干个 $2$ 凑成，答案$\mod100003$。

### 思路
> - 完全背包问题，物品无限个，求方案数。  
> - 状态定义：$dp_i$ 表示凑成 $i$ 元钱的方案数。  
> - 状态转移：$dp_i=dp_i+dp_{i-a_j}$ ，其中 $a_j$ 是第 $j$ 件物品的价格。  
> - 初始化：$dp_0 = 1$，凑成 $0$ 元钱只有一种方案，就是不选任何物品。  
> - 最终答案：$dp_t$。  
 
### 代码
```cpp
#include<bits/stdc++.h>
using namespace std;
long long n,f[5010];
int main(){
	cin>>n;
	f[0]=1;
	f[1]=1;
	for(int i=2;i<=n;i++){
        f[i]=f[i-1]+f[i-2];
        f[i]%=100003;
    }
	cout<<f[n];
	return 0;
} 
```

## T692108 落落的凑钱问题 2

### 题意简化
> - 求用无限张面值为 $1$ 到 $k$ 的纸币凑出 $t$ 元的方案数$\bmod 100003$。

### 思路
> - 完全背包问题，物品无限个，求方案数。
> - 状态定义：$dp_i$ 表示凑成 $i$ 元钱的方案数。
> - 状态转移：$dp_i=dp_i+dp_{i-a_j}$ ，其中 $a_j$ 是第 $j$ 件物品的价格。
> - 初始化：$dp_0 = 1$，凑成 $0$ 元钱只有一种方案，就是不选任何物品。
> - 最终答案：$dp_t$。

### 代码
```cpp
#include<bits/stdc++.h>
using namespace std;
long long n,k,f[5010];
int main(){
	cin>>n>>k;
	f[0]=1;
	for(int i=1;i<=n;i++){
        for(int j=1;j<=k;j++){
            if(i-j>=0) f[i]=(f[i]+f[i-j])%100003;
        }
    }
	cout<<f[n];
	return 0;
} 
```

## T692108 落落的凑钱问题 3

### 题意简化
> - 求用无限张面值为 $a_1$ 到 $a_n$ 的纸币凑出 $t$ 元的方案数$\bmod 100003$。

### 思路
> - 完全背包问题，物品无限个，求方案数。
> - 状态定义：$dp_i$ 表示凑成 $i$ 元钱的方案数。
> - 状态转移：$dp_i=dp_i+dp_{i-a_j}$ ，其中 $a_j$ 是第 $j$ 张纸币的面值。
> - 初始化：$dp_0 = 1$，凑成 $0$ 元钱只有一种方案，就是不选任何纸币。
> - 最终答案：$dp_t$。

### 代码
```cpp
#include<bits/stdc++.h>
using namespace std;
long long n,k,f[5010],a[5010];
int main(){
	cin>>n>>k;
    for(int i=1;i<=k;i++){
        cin>>a[i];
    }
	f[0]=1;
	for(int i=1;i<=n;i++){
        for(int j=1;j<=k;j++){
            if(i-a[j]>=0) f[i]=(f[i-a[j]]+f[i])%100003;
        }
    }
	cout<<f[n];
	return 0;
} 
```

## T692108 落落的凑钱问题 4

### 题意简化
> - 求用无限张面值为 $a_1$ 到 $a_n$ 的纸币凑出 $t$ 元的最少纸币数量$\bmod 100003$。

### 思路
> - 完全背包问题，物品无限个，求最少物品数量。
> - 状态定义：$dp_i$ 表示凑成 $i$ 元钱的最少纸币数量。
> - 状态转移：$dp_i=\min(dp_i,dp_{i-a_j}+1)$ ，其中 $a_j$ 是第 $j$ 张纸币的面值。
> - 初始化：$dp_0 = 0$，凑成 $0$ 元钱需要 $0$ 张纸币。
> - 最终答案：$dp_t$。

### 代码
```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define ll long long

const int N = 1e7 + 10, MOD = 100003;
ll n, t, a[N];
ll dp[N]; // 刚好凑到i元时，使⽤的最少的纸币张数

int main() {
    cin >> t >> n;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }
    
    fill(dp, dp + N, 1e9); // 初始化:⼀开始都需要⽆穷多纸币
    dp[0] = 0;
    
    for (int i = 1; i <= t; i++) {
        for (int j = 1; j <= n; j++) {
            if (i - a[j] >= 0) {
                // 类似最⻓上升⼦序列，从前⾯最⼩的符合条件的dp[j]转移
                dp[i] = min(dp[i], dp[i - a[j]] + 1);
            }
        }
    }
    
    if (dp[t] != INT_MAX) 
        cout << dp[t];
    else 
        cout << -1;
    
    return 0;
}
```
