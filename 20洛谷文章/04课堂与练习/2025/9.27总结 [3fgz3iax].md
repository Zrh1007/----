# P4995 跳跳！

## 简化题意
> 给定一个数组 $h$，每个元素只可访问一次，求所有 $(h_i-h_j)^2$ 总和的最大值。

## 思路
> 1\.双指针+贪心
> - 首先对数组进行排序，然后使用双指针从两端向中间遍历，计算每对元素的差的平方并累加到总和中。

> 注意
> - 首先需要对数组进行排序，以便使用双指针方法。

> 2\.复杂度分析
> - 时间复杂度：$O(N \log N)$，主要是排序的时间复杂度。
> - 空间复杂度：$O(1)$，只使用了少量变量。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
long long n,sum;
int a[310];
int main(){
	cin>>n;
	for(int i=1;i<=n;i++){
		cin>>a[i];
	}
	sort(a+1,a+1+n);
	int i=0,j=n;
	while(i<j){
		sum+=(a[i]-a[j])*(a[i]-a[j]);
		i++;
		sum+=(a[i]-a[j])*(a[i]-a[j]);
		j--;
	}
	cout<<sum;
	return 0;
}
```

# T670094 数字交换

## 简化题意
> 有一组数（设有N个）。编一程序交换这组数中任意指定的两段。(两段不重合，且这两段的数字个数一样)

## 思路
> 1\. 模拟
> - 使用数组存储输入的数字，双指针分别指向两段的起始位置，逐个交换对应位置的数字。

> 2\. 复杂度分析
> - 时间复杂度：$O(N)$，需要遍历数组进行交换操作。
> - 空间复杂度：$O(1)$，只使用了少量变量

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
int n,a[22],l1,r1,l2,r2;
int main(){
	cin>>n;
	for(int i=1;i<=n;i++){
		cin>>a[i];
	}
	cin>>l1>>r1>>l2>>r2;
	for(int i=l1,j=l2;i<=r1&&j<=r2;i++,j++){
		swap(a[i],a[j]);
	}
	for(int i=1;i<=n;i++){
		cout<<a[i]<<' ';
	}
	return 0;
}
```

# P14063 [PO Final 2022] 海滩 / Badstrand

## 简化题意
> 给定一个数组 $h$，求连续区间不超过 $b$ 的最大总和。

## 思路
> 注意
> - 此题有两种解法，一种是前缀和+二分，另一种是双指针。这里使用前缀和+二分的方法。

> 1\. 模拟
> - 首先遍历每个区间，然后求和。
> - 时间复杂度为 $O(N^2)$，会超时。

> 2\. 前缀和+二分
> - 计算前缀和数组 `sum`，其中 `sum[i]` 表示前 `i` 个元素的和。
> - 对于每个起点 `i`，使用二分查找找到最大的终点 `j`，使得 `sum[j] - sum[i] <= b`。

> 3\. 复杂度分析
> - 时间复杂度：$O(N \log N)$，每个起点进行一次二分查找。
> - 空间复杂度：$O(N+N)$，需要存储前缀和数组。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
int n,b,a[100010],c=-1e9;
long long sum[100010];
int main(){
	cin>>n>>b;
	for(int i=1;i<=n;i++){
		cin>>a[i];
		sum[i]=sum[i-1]+a[i];
	}
	for(int i=0;i<=n;i++){
		int l=i,r=n,res=0;
        while(l<=r){
            int mid=(l+r)/2;
            if(sum[mid]-sum[i]<=b){
                res=mid;
                l=mid+1;
            }
			else r=mid-1;
        }
		c=max(res-i,c);
	}
	cout<<c;
	return 0;
}
```
