# U573075 123

## 题意简化
> 给定n个城市的距离和游玩时间，求每天至少需要赶路多少距离才能在m天内游玩所有城市。

## 题解
> 1.暴力
> - 枚举每天赶路的距离，从1开始，计算总共需要多少天，如果小于等于m天则输出当前距离。

> [!info]+ 暴力代码
>
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> long long n,m;
> long long a[100010],sum_t;
> bool check(long long mid){
>     long long cnt=0;
>     for(int i=1;i<=n;i++){
>         cnt+=ceill((double)a[i]/mid);
>     }
>     return sum_t + cnt <= m;
> }
> int main(){
>     ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
>     cin>>n>>m;
>     for(long long i=1;i<=n;i++){
>         long long x;
>         cin>>a[i]>>x;
>         sum_t+=x;
>     }
>     if(sum_t>m||m==0){
>         cout<<-1;
>         return 0;
>     }
>     for(long long i=1;i<=1e15;i++){
>         if(check(i)){
>             cout<<i;
>             return 0;
>         }
>     }
>     cout<<-1;
>     return 0;
> } return 0;
> }
> ```


> [!warning]+ 时间复杂度
>
> - 时间复杂度：$O(n\log n)$，其中$n$是城市数量。
> - 由于题目数据范围为$1 \le n \le 10^5$，暴力解法会超时。

> 2.二分答案
> - 使用二分搜索来找到每天赶路的最小距离。在`check`函数中，计算总共需要多少天，如果小于等于m天则返回true，否则返回false。

> [!success]+ 二分代码
>
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> long long n,m;
> long long a[100010],sum_t;
> bool check(long long mid){
>     long long cnt=0;
>     for(int i=1;i<=n;i++){
>         cnt+=ceill((double)a[i]/mid);
>     }
>     return sum_t + cnt <= m;
> }
> int main(){
>     ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
>     cin>>n>>m;
>     for(long long i=1;i<=n;i++){
>         long long x;
>         cin>>a[i]>>x;
>         sum_t+=x;
>     }
>     if(sum_t>m||m==0){
>         cout<<-1;
>         return 0;
>     }
>     long long l=0,r=1e17;
>     while(l+1<r){
>         long long mid=(l+r)/2;
>         if(check(mid)) r=mid;
>         else l=mid;
>     }
>     cout<<r;
>     return 0;
> }
> ```
>


> [!success]+ 时间复杂度
>
> - 时间复杂度：$O(n \log (max\_distance))$，其中$max\_distance$是城市之间的最大距离。

# T709058 最小化数组中的最大值

## 题意简化
> 给定一个包含n个非负整数的数组nums。每次操作可以选择一个下标i（2 ≤ i ≤ n），将nums[i]减1，并将nums[i-1]加1。问经过任意次操作后，数组中的最大值最小是多少。

## 题解
> 1.模拟
> - 计算数组的前缀和，并在每一步中计算当前前缀和与当前位置的平均值，取最大值作为结果。

> [!info]+ 模拟代码
>
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> long long n,a[100010],b[100010];
> bool check(long long x){
>     for(long long i=1;i<=n;i++){
>         b[i]=a[i];
>     }
>     for(long long i=n;i>=2;i--){
>         if(b[i]>x){
>             b[i-1]+=(b[i]-x);
>         }
>     }
>     return b[1]<=x;
> }
> int main(){
>     ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
>     cin>>n;
>     int maxn=-1e9;
>     for(long long i=1;i<=n;i++){
>         cin>>a[i];
>         maxn=max(maxn,a[i]);
>     }
>     for(long long i=1;i<=maxn;i++){
>         if(check(i)){
>             cout<<i;
>             return 0;
>         }
>     }
>     return 0;
> }
> ```


> [!warning]+ 时间复杂度
>
> - 时间复杂度：$O(n^3)$。
> - 由于题目数据范围为$2 \leq n \leq 10^5，0 \leq nums[i] \leq 10^9$，模拟解法会超时。

> 2.二分答案
> - 使用二分搜索来找到数组中的最大值最小值。在`check`函数中，模拟操作过程，判断是否可以将数组中的最大值减小到mid。

> [!success]+ 二分代码
>
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> long long n,a[100010],b[100010];
> bool check(long long x){
>     for(long long i=1;i<=n;i++){
>         b[i]=a[i];
>     }
>     for(long long i=n;i>=2;i--){
>         if(b[i]>x){
>             b[i-1]+=(b[i]-x);
>         }
>     }
>     return b[1]<=x;
> }
> int main(){
>     ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
>     cin>>n;
>     for(long long i=1;i<=n;i++){
>         cin>>a[i];
>     }
>     long long l=0,r=1e9;
>     while(l+1<r){
>         long long mid=(l+r)/2;
>         if(check(mid)) r=mid;
>         else l=mid;
>     }
>     cout<<r;
>     return 0;
> }
> ```


> [!success]+ 时间复杂度
>
> - 时间复杂度：$O(n \log n)$。
