# T701698 统计因子

## 题意简化
> 给定一个整数数组 $a$ ，求所有数组元素因子数量之和。

## 题解
> 1.模拟
> - 遍历数组中每个元素，计算其因子数量并累加。
> ::::info[模拟代码]{open}
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int n, a[1000010], cnt;
> int f(int x) {
>    int ans = 0;
>    for (int i = 1; i * i <= x; i++) {
>        if (x % i == 0) {
>            ans++;
>            if (i != x / i) {
>                ans++;
>            }
>        }
>    }
>    return ans;
> }
>
> int main() {
>    ios::sync_with_stdio(0);
>    cin.tie(0);
>    cout.tie(0);
>    cin >> n;
>    for (int i = 1; i <= n; i++) {
>        cin >> a[i];
>        cnt += f(a[i]);
>    }
>    cout << cnt;
>    return 0;
> }
> ```
> ::::
> ::::error[时间复杂度]{open}
> - 时间复杂度：$O(n \sqrt{m})$，其中 $n$ 是数组长度，$m$ 是数组中最大元素，会超时。
> ::::
> 2.枚举+预处理
> - 预处理 $1~10^6$ 每个数的因子数量。具体的，遍历 $1~10^6$ 的每个数，每次将这个数的倍数的因子数量加一。
> - 遍历数组，直接累加预处理好的因子数量。
> ::::success[预处理代码]{open}
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> int n,a[1000005],ans;
> int cnt[1000005];
> int main(){
>    ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
>    cin>>n;
>    for(int i=1;i<=n;i++) cin>>a[i];
>    for(int i=1;i<=1000000;i++){
>        for(int j=i;j<=1000000;j+=i){
>            cnt[j]++;
>        }
>    }
>    for(int i=1;i<=n;i++) ans+=cnt[a[i]];
>    cout<<ans;
>    return 0;
> }
> ```
> ::::
> ::::success[时间复杂度]{open}
> - 时间复杂度：$O(n + m \log m)$，其中 $n$ 是数组长度，$m$ 是数组中最大元素。预处理部分的时间复杂度为 $O(m \log m)$，遍历数组部分的时间复杂度为 $O(n)$。
> ::::

# T701714 排队

## 题意简化
> 给定一个空队列，定义操作`1 x`表示将 $x$ 入队，操作`2`表示出队并输出出队元素，操作`3`表示将队列进行升序排序。请实现该队列。

## 题解
> 1.模拟
> - 使用一个数组模拟队列，创建两个指针`head`和`tail`，分别指向队首和队尾。
> - 当进行操作`1 x`时，将 $x$ 放入`tail`位置，并将`tail`后移一位。
> - 当进行操作`2`时，输出`head`位置的元素，并将`head`后移一位。
> - 当进行操作`3`时，对`head`到`tail-1`范围内的元素进行排序。
> ::::info[模拟代码]{open}
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> int a[200010];
> int n;
> int main(){
>     ios::sync_with_stdio(0);
>     cin.tie(0);
>     cout.tie(0);
>     cin>>n;
>    int cnt=1,ans=1;
>    for(int i=1;i<=n;i++){
>        int op;
>        cin>>op;
>        if(op==1){
>            int x;
>            cin>>x;
>            a[cnt]=x;
>            cnt++;
>        }
>        if(op==2){
>            cout<<a[ans]<<'\n';
>            ans++;
>        }
>        if(op==3){
>            if(ans<cnt){
>                sort(a+ans,a+cnt);
>            }
>        }
>    }
>    return 0;
> }
> ```
> ::::
> ::::error[时间复杂度]{open}
> - 时间复杂度：最坏情况下为 $O(n^2 \log n)$，当有大量的排序操作时会超时。
> ::::
> 2.使用优先队列
> - 使用一个普通队列和一个优先队列，分别存储未排序和已排序的元素。
> - 当进行操作`1 x`时，将 $x$ 放入普通队列。
> - 当进行操作`2`时，如果优先队列不为空，则输出优先队列的队首元素并将其弹出；否则输出普通队列的队首元素并将其弹出。
> - 当进行操作`3`时，将普通队列中的所有元素弹出并放入优先队列。
> ::::success[优先队列代码]{open}
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> int a[200010];
> int n;
> int main(){
>    ios::sync_with_stdio(0);
>    cin.tie(0);
>    cout.tie(0);
>    cin>>n;
>    int cnt=1,ans=1;
>    for(int i=1;i<=n;i++){
>        int op;
>        cin>>op;
>        if(op==1){
>            int x;
>            cin>>x;
>            a[cnt]=x;
>            cnt++;
>        }
>        if(op==2){
>            cout<<a[ans]<<'\n';
>            ans++;
>        }
>        if(op==3){
>            if(ans<cnt){
>                sort(a+ans,a+cnt);
>            }
>        }
>    }
>    return 0;
> }
> ```
> ::::
> ::::success[时间复杂度]{open}
> - 时间复杂度：$O(n \log n)$，每个元素最多被插入和弹出优先队列一次。
> ::::
