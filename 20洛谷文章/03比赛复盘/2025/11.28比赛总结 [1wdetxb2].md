# T703101 小梦的V图

## 题意简化
> 选择三个下标 $(i,j,k)$，满足：$i<j<k$ 且 $a_i>a_j$ 且 $a_j<a_k$，以最大化 $a_i+a_j+a_k$ 的值。

## 题解
> 1.模拟
> - 遍历所有可能的下标 $j$ ，并枚举 $i,k$。

> [!info]+ 模拟代码
>
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> int main(){
>     ios::sync_with_stdio(false);
>     cin.tie(nullptr);
>     int n;
>     cin>>n;
>     vector<long long>a(n);
>     for(int i=0;i<n;i++)cin>>a[i];
>     long long ans=0; //若不存在 V 型，输出 0
>     //纯模拟：枚举所有 i<j<k
>     for(int i=0;i<n;i++){
>         for(int j=i+1;j<n;j++){
>             if(a[i]>a[j]){                 //a_i>a_j
>                 for(int k=j+1;k<n;k++){
>                     if(a[j]<a[k]){         //a_j<a_k
>                         ans=max(ans,a[i]+a[j]+a[k]);
>                     }
>                 }
>             }
>         }
>     }
>     cout<<ans<<"\n";
>     return 0;
> }
> ```


> [!danger]+ 时间复杂度
>
> - 时间复杂度：$O(n^3)$，会超时。

> 2.前后缀最大值
> - 使用两个数组 `sum1` 和 `sum2` 分别记录每个位置左侧和右侧的最大值。
> - 遍历数组，计算满足条件的 $j$ 的最大值。

> [!success]+ 前后缀代码
>
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> long long n,a[500010],sum1[500010],sum2[500010];
> int main(){
>     ios::sync_with_stdio(0);
>     cin.tie(0);
>     cout.tie(0);
>     cin>>n;
>     long long maxn=-1e18;
>     for(int i=1;i<=n;i++){
>         cin>>a[i];
>         if(i>1){//避免访问 a[i-1]时的边界问题
>             maxn=max(maxn,a[i-1]);
>         }
>         sum1[i]=maxn;//记录左侧的最大值
>     }
>     
>     maxn=-1e18;
>     for(int i=n;i>=1;i--){
>         if(i<n){//避免访问 a[i+1]时的边界问题
>             maxn=max(maxn,a[i+1]);
>         }
>         sum2[i]=maxn;//记录右侧的最大值
>     }
>     
>     long long result=-1e18;
>     for(int i=2;i<n;i++){
>         if(sum1[i]>a[i]&&a[i]<sum2[i]){
>             result=max(result,sum1[i]+a[i]+sum2[i]);
>         }
>     }
>     
>     if(result==-1e18){
>         cout<<0;
>     } else{
>         cout<<result;
>     }
>     return 0;
> }
> ```


> [!success]+ 时间复杂度
>
> - 时间复杂度：$O(n)$。

# U636247 数组乘积

## 题意简化
> 给定一个长度为$n$的整数数组$nums$，定义$answer[i]$=$nums$中除$nums[i]$ 之外所有数字的乘积 $\bmod 1e9+7$，求数组$answer$。

## 题解
> 1.模拟
> - 遍历所有可能的下标 $j$ ，并枚举 $i,k$。

> [!info]+ 模拟代码
>
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> int main(){
>     ios::sync_with_stdio(false);
>     cin.tie(nullptr);
>     int n;
>     cin>>n;
>     vector<long long>a(n);

>     long long ans=0; //若不存在 V 型，输出 0
>     //纯模拟：枚举所有 i<j<k
>     for(int i=0;i<n;i++){
>         for(int j=i+1;j<n;j++){
>             if(a[i]>a[j]){                 //a_i>a_j

>                     if(a[j]<a[k]){         //a_j<a_k

>                     }
>                 }
>             }
>         }
>     }
>     cout<<ans<<"\n";

> [!danger]+ 时间复杂度
