# T708239 二分答案专题1-1

## 题意简化
> 给定正整数$n$，求$x$的最小值，使得$x+\lfloor\frac{x}{3}\rfloor+\lfloor\frac{\lfloor\frac{x}{3}\rfloor}{3}\rfloor+\cdots \geq n$。

## 题解
> 1.暴力
> - 枚举从$1$到$n$的所有$x$，计算其满足条件的值，找到第一个满足条件的$x$并输出。

> [!info]+ 暴力代码
>
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> int n;
> int check(int x){
>     int cnt=x,mg=x;
>     while(cnt>=3){
>         int tmp = cnt / 3;
>         cnt%=3;
>         cnt+=tmp;
>         mg+=tmp;
>     }
>     return mg>=n;
> }
> int main(){
>     ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
>     cin>>n;
>     for(int i=1;i<=n;i++){
>         if(check(i)){
>             cout<<i;
>             break;
>         }
>     }
>     return 0;
> }
> ```


> [!warning]+ 时间复杂度
>
> - 时间复杂度：$O(n\log n)$，其中$\log n$是计算每个$x$时的复杂度。
> - 由于题目数据范围为$1\leq n\leq10^8$，暴力解法会超时。

> 2.二分答案
> - 设定二分搜索的范围为$[1, n]$，对于每个中间值`mid`，计算其满足条件的值，如果满足条件则更新答案并缩小右边界，否则扩大左边界。最终输出答案。

> [!success]+ 二分代码
>
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> int n;
> int check(int x){
>     int cnt=x,mg=x;
>     while(cnt>=3){
>         int tmp = cnt / 3;
>         cnt%=3;
>         cnt+=tmp;
>         mg+=tmp;
>     }
>     return mg>=n;
> }
> int main(){
>     ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
>     cin>>n;
>     for(int i=1;i<=n;i++){
>         if(check(i)){
>             cout<<i;
>             break;
>         }
>     }
>     return 0;
> }
> ```
>


> [!success]+ 时间复杂度
>
> - 时间复杂度：$O(\log n \cdot \log n)$，其中$\log n$是二分搜索的复杂度，另一个$\log n$是计算每个`mid`时的复杂度。

# T708240 二分答案专题1-2

## 题意简化
> 给定一个正整数序列 $a$，求 $a_i+a_j\geq a_k$ 且 $i<j<k$ 的三元组个数。

## 题解
> 1.模拟
> - 枚举每个可能的 $(i,j,k)$，然后判断是否满足 $a_i+a_j\geq a_k$ ，如果满足则计数。

> [!info]+ 模拟代码
>
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> int n,a[8010];
> int main(){
>     ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
>     cin>>n;
>     for(int i=1;i<=n;i++){
>         cin>>a[i];
>     }
>     sort(a+1,a+1+n);
>     int cnt=0;
>     for(int i=1;i<n-1;i++){
>         for(int j=i+1;j<n;j++){
>             for(int k=j+1;k<=n;k++){
>                 if(a[i]+a[j]>a[k]){
>                     cnt++;
>                 }
>             }
>         }
>     }
>     cout<<cnt;
>     return 0;
> }
> ```


> [!warning]+ 时间复杂度
>
> - 时间复杂度：$O(n^3)$。
> - 由于题目数据范围为$1\leq n\leq8000$，模拟解法会超时。

> 2.二分答案
> - 先对数组进行排序，然后枚举每对 $(i,j)$，使用`lower_bound` 找到第一个不满足 $a_i+a_j\geq a_k$ 的位置 `pos`，则满足条件的 $k$ 的个数为 `pos - (j + 1)`，累加到答案中。

> [!success]+ 二分代码
>
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> long long n,a[8010];
> int main(){
>     ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
>     cin>>n;
>     for(long long i=1;i<=n;i++){
>         cin>>a[i];
>     }
>     sort(a+1,a+1+n);
>     long long cnt=0;
>     for(long long i=1;i<n-1;i++){
>         for(long long j=i+1;j<n;j++){
>             long long pos=lower_bound(a+1,a+1+n,a[i]+a[j])-a;
>             long long l=j+1;
>             long long r=pos-1;
>             cnt+=r-l+1;
>         }
>     }
>     cout<<cnt;
>     return 0;
> }
> ```


> [!success]+ 时间复杂度
>
> - 时间复杂度：$O(n^2 \log n)$。

# T708241 二分答案专题1-3

## 题意简化
>  给定多组数据，每组数据包含两个正整数 $n$ 和 $m$，求需要几次 $n-m$ 并 $m-1$ 才能使 $n$ 或 $m$ 为 $0$，并输出谁先为 $0$。  

## 题解
> 1.模拟
> - 每次将 $n$ 减去 $m$，并将 $m$ 减去 $1$，直到 $n$ 或 $m$ 为 $0$，记录操作次数并输出结果。

> [!info]+ 模拟代码
>
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> int t;
> int main(){
>     ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
>     cin>>t;
>     while(t--){
>         int n,m;
>         cin>>n>>m;
>         int time=1;
>         while(1){
>             n-=m;
>             if(n<=0){
>                 cout<<"NO\n";
>                 break;
>             }
>             time++;
>             m--;
>             if(m<=0){
>                 cout<<"YES\n";
>                 break;
>             }
>         }
>         cout<<time<<'\n';
>     }
>     return 0;
> }
> ```


> [!warning]+ 时间复杂度
>
> - 时间复杂度：$O(t \cdot (n + m))$。
> - 由于题目数据范围为$1\le T\le 2\times 10^5,1 \le n,m\le 10^9$，模拟解法会超时。

> 2.数学推导+二分答案
> - 通过数学推导可以得出，当 $n > m(m+1)/2$ 时，$m$ 会先变为 $0$，否则 $n$ 会先变为 $0$。使用二分搜索来找到满足条件的最小操作次数。

> [!success]+ 二分代码
>
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> long long t;
> void solve(long long x,long long y){
>     long long l=0;
>     long long r=y+2;
>     while(l+1<r){
>         long long mid=(l+r)/2;
>         if(((y)+(y-mid+1))*mid/2>=x){
>             r=mid;
>         }
>         else l=mid;
>     }
>     cout<<r<<'\n';
>     return;
> }
> int main(){
>     ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
>     cin>>t;
>     while(t--){
>         long long n,m;
>         cin>>n>>m;
>         if(n>m*(m+1)/2){
>             cout<<"YES\n";
>             cout<<m+1<<'\n';
>         }
>         else{
>             cout<<"NO\n";
>             solve(n,m);
>         }
>     }
>     return 0;
> }
> ```


> [!success]+ 时间复杂度
>
> - 时间复杂度：$O(t \log m)$。

# T708242 二分答案专题1-4

### 题意简化
> - 给定一个序列 $a$，每次从中选取 $k$ 个不同的元素，各减 $1$，直到无法再选取 $k$ 个不同的非零元素为止，求最多可以进行多少次这样的操作。

### 题解
> 1.暴力
> - 每次使用优先队列选取前 $k$ 个不同的非零元素，然后将其减 $1$，直到无法再选取 $k$ 个不同的非零元素为止。

> [!info]+ 暴力代码
>
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> long long a[200010],n,k,ans;
> priority_queue<long long,vector<long long>,less<long long>> q;
> int main(){
> 	cin>>n>>k;
> 	for(long long i=1;i<=n;i++){
> 		cin>>a[i];
> 		q.push(a[i]);
> 	}
> 	while(q.size()>=k){
> 		long long x=k,y=1;
> 		vector<long long>op;
> 		while(x--){
> 			op.push_back(q.top());
> 			q.pop();
> 		} 
> 		ans+=y;
> 		for(long long i=0;i<op.size();i++){
> 			if(op[i]-y>0){
> 				q.push(op[i]-y);
> 			}
> 		}
> 	}
> 	cout<<ans;
> 	return 0;
> }
> ```


> [!warning]+ 时间复杂度
>
> - 时间复杂度：$O(n^2 \log k)$。
> - 题目中 $n \leq 200000$，$k \leq 100$，暴力算法超时。

> 2.二分答案
> - 先对数组进行排序，然后枚举每一个 $k$，使用二分搜索找到第一个不满足条件的 $k$ 的值，即 $k$ 最小的满足条件的 $k$。

> [!success]+ 二分代码
>
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> long long n,k;
> long long a[500010];
> bool check(long long x){
>     long long sum=0;
>     for(long long i=1;i<=n;i++){
>         sum+=min(a[i],x);
>     }
>     return sum>=x*k;
> }
> int main(){
>     ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
>     long long l=0-1,r=0;
>     cin>>n>>k;
>     for(long long i=1;i<=n;i++){
>         cin>>a[i];
>         r+=a[i];
>     }
>     r/=k;
>     r++;
>     while(l+1<r){
>         long long mid=(l+r)/2;
>         if(check(mid)) l=mid;
>         else r=mid;
>     }
>     cout<<l;
>     return 0;
> }
> ```


> [!success]+ 时间复杂度
>
> - 时间复杂度：$O(n \log \frac{r}{k} + \log k)$。
> - 其中 $r$ 是数组元素的和，$k$ 是选取元素的个数。


> 3.贪心（**伪算法**）

> [!danger]+ 贪心
>
> - 贪心算法并不适用于此题，因为无法保证单调性，这个板块只是一个错误示范。

> - 设定一个计数器 `cnt`，每次从数组中选取前 $k$ 个不同的非零元素，将其减到不可选取的状态，并将 `cnt` 加减去的数，直到无法再选取 $k$ 个不同的非零元素为止。
> - 这种方法无法保证每次选取的 $k$ 个元素都是最优的，因此不能保证得到正确的答案。
> - 例如：
> ```cpp
> 4 2
> 5 4 4 1
> ```
> - 贪心算法会选择 $5$ 和 $4$，然后选择 $4$ 和 $1$，总共减去 $4+1=5$ 次。
> - 正确答案应该是选择 $5$ 和 $4$，变成`4 3 4 1`，然后选择 $4$ 和 $4$，变成 `3 3 3 1`，再选择 $3$ 和 $3$，变成 `2 2 3 1`，最后选择 $3$ 和 $2$，变成 `1 2 2 1`，剩下还可以选 $3$ 个，总共减去 $1+1+1+1+3=7$ 次。
> - 因此，贪心算法并不能保证得到正确的答案。

# T708279 二分答案专题1-5

## 题意简化
> 给定两个序列 $A,B$，设另有一个序列 $C$ 中包含了 $A,B$ 中的数两两相加的结果 ($C$ 中共有 $n\times m$ 个数)。问 $C$ 中第 $K$ 小的数是多少。

## 题解
> 1.暴力
> - 枚举 $A$ 和 $B$ 中的每个元素，将它们相加并存储在一个新的数组 $C$ 中，然后对 $C$ 进行排序，最后输出第 $K$ 个元素。

> [!info]+ 暴力代码
>
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> long long n,m,k,a[100010],b[100010],c[100010];
> int main(){
> 	cin>>n>>m>>k;
>     for(int i=1;i<=n;i++) cin>>a[i];
>     for(int i=1;i<=m;i++) cin>>b[i];
>     int cnt=1;
>     for(int i=1;i<=n;i++){
>         for(int j=1;j<=m;j++){
>             c[cnt]=a[i]+b[j];
>             cnt++;
>         }
>     }
>     sort(a+1,a+1+cnt);
>     cout<<a[k];
> 	return 0;
> }
> ```


> [!warning]+ 时间复杂度
>
> - 时间复杂度：$O(n \times m \log (n \times m))$。
> - 由于题目数据范围为 $1 \leq n,m \leq 10^7$，暴力解法会超时。

> 2.二分答案
> - 先对数组 $A$ 和 $B$ 进行排序，然后使用二分搜索来找到第 $K$ 小的数。在`check` 函数中，还需要使用`upper_bound`来计算满足条件的元素个数，然后调整搜索区间。
> - 最终输出二分搜索的结果。

> [!success]+ 二分代码
>
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> int n,m,k,a[100010],b[100010];
> bool check(int x){
>     int cnt=0;
>     for(int i=1;i<=n;i++){
>         cnt+=(upper_bound(b+1,b+1+m,x-a[i])-b-1);
>     }
>     return cnt>=k;
> }
> int main(){
>     ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
>     cin>>n>>m>>k;
>     for(int i=1;i<=n;i++){
>         cin>>a[i];
>     }
>     for(int i=1;i<=m;i++){
>         cin>>b[i];
>     }
>     sort(a+1,a+1+n);
>     sort(b+1,b+1+m);
>     int r=a[n]+b[m]+1;
>     int l=2-1;
>     while(l+1<r){
>         int mid=(l+r)/2;
>         if(check(mid)) r=mid;
>         else l=mid;
>     }
>     cout<<r;
>     return 0;
> }
> ```
