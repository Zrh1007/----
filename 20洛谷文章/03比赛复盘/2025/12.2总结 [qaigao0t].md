# T705025 期望的查询2

## 题意简化
> 给定两个字符串`s`和`t`，求字符串`s`在 $s_l~s_r$ 中是`t`的出现次数。

## 题解
> 1.前缀和
> - 使用前缀和数组`sum`，`sum[i]`表示字符串`s`中前`i`个字符中`t`出现的次数。

> [!success]+ 前缀和代码
>
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> int n,m,q;
> int sum[100010];
> string a,b;
> int main(){
>     ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
>     cin>>n>>m>>q;
>     cin>>a>>b;
>     a='#'+a;
>     b='#'+b;
>     for(int i=1;i<=n;i++){
>         bool f=1;
>         for(int j=1;j<=m;j++){
>             if(a[i+j-1]!=b[j]){
>                 f=0;
>                 break;
>             }
>         } 
>         if(f){
>             sum[i]=sum[i-1]+1;
>         }
>         else{
>             sum[i]=sum[i-1]+0;
>         }
>     }
>     while(q--){
>         int x,y;
>         cin>>x>>y;
>         y=y-m+1;
>         cout<<sum[y]-sum[x-1]<<'\n';
>     }
>     return 0;
> }
> ```


> [!success]+ 时间复杂度
>
> - 时间复杂度：$O(n*m+q)$。

# T705026 期望的查询3

## 题意简化
> 给出两个奇数 $l_i$ 和 $r_i$，请你求出满足 $l_i \leq x \leq r_i$ 且 $x$ 满足“$N$ 和 $(N+1)÷2$ 都是素数”的奇数 $x$ 的个数。

## 题解
> 1.筛法+前缀和
> - 使用筛法预处理出所有素数，然后使用前缀和数组`sum`，`sum[i]`表示小于等于`i`且满足题意的奇数个数。

> [!success]+ 并查集代码
>
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int sum[100010];
> int vis[100010];
> int main(){
> 	vis[0] = vis[1] = 1;
> 	for(int i = 2; i <= 100000; i++)
> 	{
> 		if(!vis[i])
> 		{
> 			for(int j = i * 2; j <= 100000; j += i)
> 			{
> 				vis[j] = 1;
> 			}
> 		}
> 	}
> 	for(int i = 1; i <= 100000; i++)
> 	{
> 		if(vis[i] == 0 && vis[(i + 1) / 2] == 0)
> 		{
> 			sum[i] = sum[i - 1] + 1;
> 		}
> 		else
> 		{
> 			sum[i] = sum[i - 1] + 0;
> 		}
> 	}
> 	int n;
> 	cin >> n;
> 	for(int i = 1; i <= n; i++)
> 	{
> 		int l, r;
> 		cin >> l >> r;
> 		cout << sum[r] - sum[l - 1] << '\n';
> 	}
> 	return 0;
> }
>
> ```


> [!success]+ 时间复杂度
>
> - 时间复杂度：$O(n\log\log n+q)$。

# T705031 期望的查询4

## 题意简化
> 给定字符串`s`，其中每个字符代表一本书的类别（`A`或`B`），以及两个整数`h_A`和`h_B`，分别代表两类书的高度。对于多个查询区间`[l, r]`，判断在该区间内，能否通过移除部分书本，使得剩余书本的高度严格递增。如果可以，输出2，否则输出1。

## 题解
> 1.前缀和
> - 如果`h_A == h_B`，则所有查询答案均为1。
> - 否则，预处理一个数组`ans`，`ans[i]`表示第`i`本书是否可以作为高度递增序列中的一员（即`h_A > h_B`时，类别为`A`的书可以作为一员，类别为`B`的书不可以，反之亦然）。然后预处理前缀和数组`pre`，`pre[i]`表示在前`i`本书中，有多少个位置满足`ans[i-1] == 0 && ans[i] == 1`。对于每个查询区间`[l, r]`，只需判断`pre[r] - pre[l]`是否大于0，若大于0则输出2，否则输出1。

> [!success]+ 前缀和代码
>
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> string s;
> int n,t;
> int h_A,h_B;
> int ans[5000010];
> int pre[5000010];
> int main(){
>     ios::sync_with_stdio(false);
>     cin.tie(0);
>     cout.tie(0);
>     cin>>n>>t;
>     cin>>h_A>>h_B;
>     cin>>s;
>     if(h_A==h_B){
>         while(t--){
>             int l,r;
>             cin>>l>>r;
>             cout<<1<<endl;
>         }
>     }
>     else{
>         int len=s.size();
>         for(int i=0;i<len;++i){
>             if(s[i]=='A'){
>                 ans[i+1]=(h_A>h_B);
>             }
>             if(s[i]=='B'){
>                 ans[i+1]=(h_B>h_A);
>             }
>         }
>         ans[0]=-1;
>         for(int i=1;i<=n;++i)
>         {
>             pre[i]=pre[i-1]+(ans[i-1]==0&&ans[i]==1);
>         }
>         while(t--)
>         {
>             int l,r;
>             cin>>l>>r;
>             l++;
>             if(pre[r]-pre[l-1]==0)
>             {
>                 cout<<1<<'\n';
>             }
>             else
>             {
>                 cout<<2<<'\n';
>             }
>         }
>     }
>     return 0;
> }
> ```



> [!success]+ 时间复杂度
>
> - 时间复杂度：$O(n+q)$。

# T705027 期望的查询5

## 题意简化
> 给定一个长度为`n`的数组`a`，判断是否存在区间`[l, r]`，使得区间内奇数位置元素和等于偶数位置元素和。

## 题解
> 1.前缀和
> - 预处理两个前缀和数组`sum1`和`sum2`，`sum1[i]`表示前`i`个元素中奇数位置元素的和，`sum2[i]`表示前`i`个元素中偶数位置元素的和。然后使用哈希表记录每个`sum1[i]-sum2[i]`出现的次数，如果某个值出现次数大于1，则说明存在区间`[l, r]`使得奇数位置元素和等于偶数位置元素和，输出"YES"，否则输出"NO"。

> [!success]+ 前缀和代码
>
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> long long a[200010],sum1[200010],sum2[200010];
> int main(){
> 	int t;
> 	cin>>t;
> 	while(t--){
>         map<long long,int> cnt;
>         int n;
>         cin>>n;
>         for(int i=1;i<=n;++i){
>             cin>>a[i];
>             if(i%2==1){
>                 sum1[i]=sum1[i-1]+a[i];
>                 sum2[i]=sum2[i-1]+0;
>             }
>             if(i%2==0){
>                 sum1[i]=sum1[i-1]+0;
>                 sum2[i]=sum2[i - 1]+a[i];
>             }
>         }
>         bool flag=1;
>         for(int r=0;r<=n;++r){
>             cnt[sum1[r]-sum2[r]]++;
>             if(cnt[sum1[r]-sum2[r]]>1){
>                 cout<<"YES"<<"\n";
>                 flag=0;
>                 break;
>             }
>         }
>         if(flag==1){
>             cout<<"NO"<<'\n';
>         }
>     }
> 	return 0;
> }
> ```
>


> [!success]+ 时间复杂度
>
> - 时间复杂度：$O(n)$。
