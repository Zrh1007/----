## 单源最短路


- Dijkstra算法

> Dijkstra算法于1956年发现，是一种求解**非负权图**单源最短路的算法。  


> [!success]+ 过程
>
> 将结点分为两个集合：已知最短路径集合 $S$ 和未知最短路径集合 $U$。初始时，所有结点都属于 $U$，且 $S$ 为空集。  
>
> 初始化 $dis[s]$ 为 $0$，$dis[u]$ 为 $INF$，$u$ 属于 $U$。  
>
> 然后重复以下操作
>     1. 从 $U$ 中选取一个结点 $u$，使 $dis[u]$ 最小，然后移动至 $S$。
>     2. 对于刚刚加入 $S$ 的结点 $u$ 的所有出边执行松弛操作。
>
> 直到 $U$ 为空集，算法结束。
> ```cpp
> struct edge{
>     int v, w;
> };
> vector<edge> e[N];
> int dis[N], vis[N];
> void dijkstra(int n, int s) {
>     memset(dis, 0x3f, (n + 1) * sizeof(int));
>     dis[s] = 0;
>     for (int i = 1; i <= n; i++) {
>         int u = 0, mind = 0x3f3f3f3f;
>         for (int j = 1; j <= n; j++)
>         if (!vis[j] && dis[j] < mind) u = j, mind = dis[j];
>         vis[u] = true;
>         for (auto ed : e[u]) {
>             int v = ed.v, w = ed.w;
>             if (dis[v] > dis[u] + w) dis[v] = dis[u] + w; //松弛操作
>         }
>     }
> }
> ``` 



> [!success]+ 时间复杂度
>
> Dijkstra算法的时间复杂度为 $O(n^2 + m)$，其中 $n$ 是结点数，$m$ 是边数。
> Dijkstra算法是在所有单源最短路算法中效率较高的一种算法，**但局限性较大**，只能处理非负边权无环图。

- Bellman-Ford算法

> [!info]+ Bellman-Ford算法
>
> Bellman-Ford算法是一种用于求解单源最短路的算法，可以处理带有负权边的图，并且能够检测图中是否存在负权环。
>
>
> > [!success]+ 过程
> >
> > 设图有 $n$ 个结点，$m$ 条边。算法重复进行 $n-1$ 轮松弛操作，每轮遍历所有边，尝试更新源点到各结点的最短距离。
> >
> > 初始化 $dis[s] = 0$，其余 $dis[u] = \infty$。
> >
> > 对于 $i = 1$ 到 $n-1$：
> >     对于每条边 $(u, v, w)$：
> >         如果 $dis[u] + w < dis[v]$，则更新 $dis[v] = dis[u] + w$。
> >
> > 完成 $n-1$ 轮后，再进行一次额外的遍历：
> >     如果存在边 $(u, v, w)$ 满足 $dis[u] + w < dis[v]$，则说明图中存在负权环。
> >
> > ```cpp
> > struct edge {
> >     int u, v, w;
> > };
> > vector<edge> e;
> > int dis[MAXN];
> >
> > bool bellman_ford(int n, int s) {
> >     memset(dis, 0x3f, sizeof(dis));
> >     dis[s] = 0;
> >     for (int i = 1; i <= n - 1; i++) {
> >         bool updated = false;
> >         for (auto ed : e) {
> >             int u = ed.u, v = ed.v, w = ed.w;
> >             if (dis[u] + w < dis[v]) {
> >                 dis[v] = dis[u] + w;
> >                 updated = true;
> >             }
> >         }
> >         if (!updated) break; // 提前终止
> >     }
> >     // 检测负权环
> >     for (auto ed : e) {
> >         int u = ed.u, v = ed.v, w = ed.w;
> >         if (dis[u] + w < dis[v]) {
> >             return false; // 存在负权环
> >         }
> >     }
> >     return true;
> > }
> > ```
>
>
>
> > [!success]+ 时间复杂度
> >
> > 时间复杂度为 $O(n \cdot m)$，其中 $n$ 是结点数，$m$ 是边数。在实际应用中，如果图比较稀疏，效率较低。
>
>
>
> > [!success]+ 正确性证明
> >
> > Bellman-Ford算法的正确性基于动态规划的思想。经过 $k$ 轮松弛后，算法能够找到从源点出发经过最多 $k$ 条边的最短路径。由于最短路径最多包含 $n-1$ 条边（否则会有环，而环如果是正权或零权则无意义，负权环则不存在最短路径），因此 $n-1$ 轮松弛足以找到所有最短路径。
>


- SPFA算法

> [!info]+ SPFA算法
>
> SPFA（Shortest Path Faster Algorithm）是Bellman-Ford算法的队列优化版本，通过队列维护待松弛的结点，减少了不必要的松弛操作，在随机图上平均时间复杂度较低，但最坏情况下仍为 $O(n \cdot m)$。
>
>
> > [!success]+ 过程
> >
> > 使用一个队列存储需要松弛的结点。初始时将源点入队，并标记其已在队列中。每次从队首取出一个结点，对其所有出边进行松弛操作。如果某个邻接点的距离被更新且不在队列中，则将其入队。重复此过程直到队列为空。
> >
> > ```cpp
> > vector<pair<int, int>> g[MAXN]; // 邻接表，存储 (v, w)
> > int dis[MAXN];
> > bool inq[MAXN]; // 是否在队列中
> > int cnt[MAXN]; // 记录入队次数，用于检测负权环
> >
> > bool spfa(int n, int s) {
> >     memset(dis, 0x3f, sizeof(dis));
> >     dis[s] = 0;
> >     queue<int> q;
> >     q.push(s);
> >     inq[s] = true;
> >     cnt[s] = 1;
> >     while (!q.empty()) {
> >         int u = q.front();
> >         q.pop();
> >         inq[u] = false;
> >         for (auto &e : g[u]) {
> >             int v = e.first, w = e.second;
> >             if (dis[u] + w < dis[v]) {
> >                 dis[v] = dis[u] + w;
> >                 if (!inq[v]) {
> >                     q.push(v);
> >                     inq[v] = true;
> >                     cnt[v]++;
> >                     if (cnt[v] > n) {
> >                         return false; // 存在负权环
> >                     }
> >                 }
> >             }
> >         }
> >     }
> >     return true;
> > }
> > ```
>
>
>
> > [!success]+ 时间复杂度
> >
> > 平均时间复杂度为 $O(k \cdot m)$，其中 $k$ 是一个较小的常数。但在最坏情况下（例如网格图）可能退化为 $O(n \cdot m)$。因此，在无负权边的图中通常使用Dijkstra算法，SPFA主要用于处理负权边或检测负权环。
>
>


## 多源最短路

- Floyd算法

> [!info]+ Floyd算法
>
> Floyd算法是一种用于求解任意两个结点之间最短路的常见算法。  
> 其基本思想是动态规划，利用动态规划的思想，可以将问题分解为子问题，从而求解原问题。  
> Floyd算法的基本思想是：对于任意两点i和j，如果经过某一点k的最短路径比经过i和j的最短路径短，则更新i到j的最短路径。  
>
> > [!success]+ 实现
> >
> > 定义一个数组 `f[k][x][y]`，表示只允许经过结点 $1$ 到 $k$ 的 $x$ 到 $y$ 的最短路径。  
> > 初始化 `f[0][i][i] = 0`，表示从结点 $i$ 到结点 $i$ 的最短路径为 $0$。  
> > 对于 $k = 1, 2, \cdots, n$，对于 $i = 1, 2, \cdots, n$，对于 $j = 1, 2, \cdots, n$，如果 `f[k][i][j]` 不是 $INF$，则更新 `f[k][i][j]` 为 `min(f[k][i][j], f[k-1][i][k] + f[k-1][k][j])`。  
> > 最后，`f[n][i][j]` 即为 $i$ 到 $j$ 的最短路径。  
> > ```cpp
> > const int N=1005;   
> > const int INF=1e9;
> > int f[N][N][N];
> > for (k = 1; k <= n; k++) {
> >   for (x = 1; x <= n; x++) {
> >     for (y = 1; y <= n; y++) {
> >       f[k][x][y] = min(f[k - 1][x][y], f[k - 1][x][k] + f[k - 1][k][y]);
> >     }
> >   }
> > }
> > ```  
> > 时间复杂度：$O(n^3)$。  
> > 显然，Floyd算法的时间复杂度较高，但其常数较低，且易于实现。
> >
> > Floyd算法可以优化其空间复杂度，因为 `f` 数组的第一维对结果无影响，所以我们发现数组的第一维是可以省略的，可以直接改成 f[x][y] = min(f[x][y], f[x][k]+f[k][y])
>
>
> > [!success]+ 证明
> >
> > 给定 $k$，当更新 `f[k][i][j]` 时，如果 `f[k-1][i][k] + f[k-1][k][j]` 不是 $INF$，则说明经过结点 $k$ 到 $i$ 和 $k$ 到 $j$ 的最短路径都比经过结点 $i$ 和 $j$ 的最短路径短，因此可以直接更新 `f[k][i][j]` 为 `f[k-1][i][k] + f[k-1][k][j]`。  
> > 因此，可以将 `f` 数组的第一维去掉，直接用 `f[x][y]` 表示 $x$ 到 $y$ 的最短路径。  
>
> ```cpp
> for (k = 1; k <= n; k++) {
>   for (x = 1; x <= n; x++) {
>     for (y = 1; y <= n; y++) {
>       f[x][y] = min(f[x][y], f[x][k] + f[k][y]);
>     }
>   }
> }
> ```

## P4779 【模板】单源最短路径（标准版）


> [!info]+ 题意
>
> 给定一个 n 个点，m 条有向边的带非负权图，请你计算从 s 出发，到每个点的距离。



> [!info]+ 题解
>
> dijkstra模板题
>
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> priority_queue<pair<int,int>,vector<pair<int,int>>,greater<pair<int,int>>> q;
> vector<pair<int,int>> g[200010];
> int n,m,S,ans;
> long long dis[200010];
> bool vis[200010];
> void dij(){
>     for(int i=1;i<=n;i++) dis[i]=1e18;
>     dis[S]=0;
>     q.push({0,S});
>     while(q.size()){
>         int u=q.top().second;
>         q.pop();
>         if(vis[u]==1) continue;
>         vis[u]=1;
>         for(int i=0;i<g[u].size();i++){
>             int v=g[u][i].second;
>             int w=g[u][i].first;
>             if(dis[u]+w<dis[v]){
>                 dis[v]=dis[u]+w;
>                 q.push({dis[v],v});
>             }
>         }
>     }
> }
> int main(){
>     ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
>     cin>>n>>m>>S;
>     while(m--){
>         int u,v,w;
>         cin>>u>>v>>w;
>         g[u].push_back({w,v});
>     }
>     dij();
>     for(int i=1;i<=n;i++){
>         if(dis[i]==1e18) cout<<-1<<' ';
>         else cout<<dis[i]<<' ';
>     }
>     return 0;
> }
> ```

    
## P3371 【模板】单源最短路径（弱化版）


> [!info]+ 题意
>
> 给定一个 n 个点，m 条有向边的带权图，可能存在负权边，请你计算从 s 出发，到每个点的距离。如果无法到达，输出 $2^{31}-1$。



> [!info]+ 题解
>
> 本题可以使用 SPFA 或 Bellman-Ford 算法，因为存在负权边。以下为 SPFA 实现。
>
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> const int MAXN = 10010;
> const int INF = 2147483647;
> vector<pair<int, int>> g[MAXN];
> int dis[MAXN];
> bool inq[MAXN];
> int n, m, s;
>
> void spfa() {
>     for (int i = 1; i <= n; i++) dis[i] = INF;
>     dis[s] = 0;
>     queue<int> q;
>     q.push(s);
>     inq[s] = true;
>     while (!q.empty()) {
>         int u = q.front(); q.pop();
>         inq[u] = false;
>         for (auto &e : g[u]) {
>             int v = e.first, w = e.second;
>             if (dis[u] + w < dis[v]) {
>                 dis[v] = dis[u] + w;
>                 if (!inq[v]) {
>                     q.push(v);
>                     inq[v] = true;
>                 }
>             }
>         }
>     }
> }
>
> int main() {
>     scanf("%d%d%d", &n, &m, &s);
>     for (int i = 0; i < m; i++) {
>         int u, v, w;
>         scanf("%d%d%d", &u, &v, &w);
>         g[u].push_back({v, w});
>     }
>     spfa();
>     for (int i = 1; i <= n; i++) {
>         if (dis[i] == INF) printf("%d ", INF);
>         else printf("%d ", dis[i]);
>     }
>     return 0;
> }
> ```


## P1144 最短路计数


> [!info]+ 题意
>
> 给定一个 n 个点，m 条边的无向无权图（边权均为 1），求从结点 1 到每个点的最短路径条数，答案对 100003 取模。



> [!info]+ 题解
>
> 由于边权均为 1，可以使用 BFS 求最短路，同时进行计数。设 $dist[i]$ 为最短距离，$cnt[i]$ 为最短路径条数。初始时 $dist[1] = 0$，$cnt[1] = 1$。BFS 过程中，如果遇到未访问的结点，则更新距离并继承计数；如果遇到已访问且距离相等的结点，则累加计数。
>
> ```cpp
> #include<bits/stdc++.h>
> using namespace std;
> const int MAXN = 1000010;
> const int MOD = 100003;
> vector<int> g[MAXN];
> int dist[MAXN], cnt[MAXN];
> bool vis[MAXN];
> int n, m;
>
> void bfs() {
>     memset(dist, 0x3f, sizeof(dist));
>     dist[1] = 0;
>     cnt[1] = 1;
>     queue<int> q;
>     q.push(1);
>     vis[1] = true;
>     while (!q.empty()) {
>         int u = q.front(); q.pop();
>         for (int v : g[u]) {
>             if (!vis[v]) {
>                 vis[v] = true;
>                 dist[v] = dist[u] + 1;
>                 cnt[v] = cnt[u];
>                 q.push(v);
>             } else if (dist[v] == dist[u] + 1) {
>                 cnt[v] = (cnt[v] + cnt[u]) % MOD;
>             }
>         }
>     }
> }
>
> int main() {
>     scanf("%d%d", &n, &m);
>     for (int i = 0; i < m; i++) {
>         int u, v;
>         scanf("%d%d", &u, &v);
>         g[u].push_back(v);
>         g[v].push_back(u);
>     }
>     bfs();
>     for (int i = 1; i <= n; i++) {
>         printf("%d\n", cnt[i]);
>     }
>     return 0;
> }
> ```
