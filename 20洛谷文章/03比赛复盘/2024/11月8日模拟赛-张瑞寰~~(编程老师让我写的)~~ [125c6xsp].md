# **比赛总结**  ~~(编程老师让我写的)~~
## A - Pairing
### 题目描述
>有四个球，第$i$个球的颜色是$A_i$。  
>找出你可以执行此操作的最大次数：选择两个相同颜色的球并丢弃它们。
### 数据范围
>* 每个$A_1,A_2,A_3,A_4$是一个介于$1$和$4$之间的整数（包括边界）
### 输入格式
>输入通过标准输入以以下格式给出：  
>$A_1$ $A_2$ $A_3$ $A_4$  
### 输出格式
>以整数形式打印可以执行操作的最大次数。

### 思路二
![](https://static.wenshushu.cn/uf/fj32oabasoa/img?st=ZmoxN3ljZWRqaGQuWkNLcjA%3D&op=zmmw-1200)
我们前段时间学了桶排序，那么我们可以也用桶排序的思路创建一个桶，用来储存每个数字的出现次数。  
代码实现：  
```cpp
#include<bits/stdc++.h>
using namespace std;
int t[5],a[4],sum;
int main(){
	cin>>a[0]>>a[1]>>a[2]>>a[3];
	for(int i=0;i<4;i++){
		t[a[i]]++;
	}
	for(int i=1;i<=4;i++){
		sum+=t[i]/2;
	}
	cout<<sum;
	return 0;
}
```
